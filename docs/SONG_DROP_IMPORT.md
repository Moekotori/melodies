# 拖拽导入歌曲

日期：2026-10-02

入口：将本地歌曲、多个文件或音乐文件夹从文件管理器拖到主窗口。拖入时显示提示，松开后显示进度与取消按钮，结束报告新增、更新、已有、失败和跳过数。导入不自动播放，不复制或移动原文件。

职责：`MainWindow.SongDrop` 只读取拖拽数据的名称和本地 URI，不访问磁盘；`ShellSongImport` 持有本次任务、串行处理有界输入并呈现结果；`DesktopLibrary` 在后台判断文件/目录，沿用同一个数据库实例与扫描准入。歌曲格式表由 Contracts 共享，文件夹继续使用原发现规则。

单文件：`SelectedFileDiscovery` 只处理选中的文件及 CUE/osu 定义引用的音频，保留嵌入 CUE 支持，不枚举其他歌曲。扫描根仍为所属目录，明确禁止部分文件导入执行 missing 清理。解析、metadata 工作者、提交批次与取消沿用现有有界扫描管线。

资源与生命周期：一次最多接收 256 个文件/目录，路径最多 4096 字符；不展开成整库列表，不建立额外导入队列。任务串行调用单一扫描 owner，活跃扫描拒绝重复准入。导航期间任务和进度继续；取消或实际退出只保留已确认提交。数据库 owner 退出时撤销其扫描 lifetime，等待管线收口后关闭数据库。隐藏/卸载主窗口视图后展示状态由 Shell 保留。

验证入口：`Echo.Library.Smoke selected-import misc/song-drop/library` 检查真实新格式 SQLite 的单文件隔离、重复导入、文件夹导入、缺失清理保护、取消与 CUE/osu 发现；`Echo.Preview --song-drop misc/song-drop/preview` 使用实际 Avalonia 拖拽事件检查过滤、去重、并发准入、切页、完成与取消，生成明暗提示和进度截图。UI 检查的导入回执为受控夹具，数据库语义由独立真实夹具验证。

本轮结果：当前源码的核心定向编译与上述七项数据库/发现检查通过，日志见 `misc/song-drop/library-final.out.log`。桌面预览构建被并行历史界面与播放构造函数尚未完成的接线阻断，另有历史/歌单 MVVM 诊断；最后一次日志见 `misc/song-drop/build-ui-latest.out.log`。仅该诊断临时降为 warning 的构建仍未通过，没有改变项目的默认检查规则。未执行 UI smoke、未产生预览截图，不宣称文件管理器实机拖入已验收。构建、定向检查与失败重跑累计约 24 秒；每条设置 30 或 45 秒超时，仅终止自己的进程树。

回滚：移除窗口拖拽接线、Shell 状态、提示层以及单文件发现分支，恢复原文件夹导入入口。数据库格式和写入 owner 没有改变，旧版工作区和生产库不参与本次修改。
