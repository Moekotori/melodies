# 专辑墙与详情迁移

日期：2026-10-02。入口：侧栏“专辑”。本轮只使用新应用曲库，未打开旧 ECHO 生产库。

## 来源与交付范围

只读对照 `D:/ECHO/src/renderer/pages/AlbumsPage.tsx`、`components/album/SteamAlbumDetailView.tsx`、`AlbumTrackList.tsx`，以及 `album-wall-layout.css`、`album-detail.css`、`album-detail-typography.css`、`album-detail-actions.css`。

专辑墙保留标题/总数、搜索、筛选、排序、方形封面、专辑名和艺术家/曲目数；列间距 20、封面到文字 14、文字间距 5。支持六种排序及方向、无损筛选、自动或 4/5/6 列、刷新与文件夹导入，Ctrl+F/Ctrl+K 聚焦搜索。

详情按旧版三栏头部重排：大封面、标题/艺术家/年份/音质与播放操作、右侧个人评分/入库日期/来源/数量。宽窗口封面 280，标题按窗口和名称长度缩放；窄窗口收起右栏。下方是居中分页标签及 56 高度曲目行，显示碟片/曲目序号、标题/艺术家、格式/位深/采样率、时长、收藏；当前曲目变化才更新播放标记。

已接实际专辑播放、单曲播放、现有播放队列追加/插入入口、个人收藏/评分及复制信息/路径。收藏和评分确认数据库结果后更新界面，返回墙面不重置滚动。详情的附件页目前展示封面；来源、当前版本及介绍页展示本地事实。网络介绍、外部评分、附件文件发现、发行版本关联、旧版标签编辑和高级版本聚合仍未迁入，不能把本轮写成旧版完整专辑功能等价。

## 职责与数据

- `Echo.Contracts/Library`：专辑分页、曲目分页、个人状态及封面字节边界。
- `Echo.Infrastructure/Library`：schema、持久化专辑索引、查询与个人状态写入。
- `Echo.Infrastructure/Artwork`：有界目录封面、FLAC picture、ID3 v2.3/v2.4 APIC 读取。
- `Echo.Desktop/Bootstrap/DesktopLibrary`：延迟打开独立曲库，查询/导入共用同一实例；退出等扫描结束后关闭数据库。
- `Features/Albums`：分页视图状态、可见卡片、图片租约、详情和轻量曲目行。Shell 仅装配入口与离页释放。

新应用默认库：`LocalApplicationData/ECHO Avalonia/library.sqlite`。`ECHO_LIBRARY_DB` 可指定已经扫描的新格式库。普通 WAV/FLAC 用既有 managed reader；其他扫描格式沿用既有 `ECHO_METADATA_SCANNER` 适配，未提供时按真实失败报告，不伪造 metadata。

Schema 由唯一 writer 从 v1 升级至 v3：v2 添加专辑聚合、FTS 和分页索引；v3 添加个人收藏/评分。首次升级回填已存在的新格式曲目；后续 insert/update/missing/delete 在原写入事务内增减专辑聚合。所有个人状态写入也进入同一有界 writer lane。

当前专辑 ID 由 trim 后的标题与专辑艺术家组成，专辑艺术家为空时使用曲目艺术家，长度编码避免分隔符碰撞。同名不同艺术家分开；旧版目录/版本/视觉证据分组未移植。已有 track ID 不改变。

默认排序和六种排序各有 `(字段,id)` 索引。墙面滚动按索引 OFFSET 随机取页；曲目按碟片/序号/稳定 ID 排序。查询不从全部曲目实时 GROUP BY；计数只针对专辑表，按 revision/搜索/筛选缓存最多 16 项。测试覆盖第 9600 张专辑附近的随机页面，更深的百万专辑场景未验证。

## 资源与取消

- 每页最多 200，墙面最多三页/600 张专辑 DTO；详情最多 200 个曲目 DTO。
- 卡片只存在于可见行及前后各一行。页面自带有限 ScrollViewer，不嵌入主窗无限滚动容器。
- 搜索防抖 120 ms，回车立即提交；请求 generation 阻止迟到结果覆盖。翻页、快速切换和离页取消待处理工作。
- SQLite 支持排队取消及读行/批次边界取消；不宣称能立即中断一个已执行 SQL 的内部阶段。
- 一个封面工作器、请求队列最多 64。编码图片最多 4 MiB，输入像素最多 16M；缩略图最长边最多 320。
- 图片缓存最多 32 MiB、192 项；只有没有活跃租约的对象可淘汰。先清除 Image.Source，再释放租约；取消的迟到图立即释放。
- 缺失或坏图显示主题占位封面；刷新释放墙面图片租约并清除无引用缓存，允许重新发现封面。
- 详情打开、窗口隐藏及离页释放墙面卡片；返回/恢复窗口重新实现可见区域。数据库和封面 worker 随窗口关闭释放。
- 专辑播放批量读取，每次最多 200、队列组装最多 1000；超大专辑明确提供单曲播放，不拉整库。
