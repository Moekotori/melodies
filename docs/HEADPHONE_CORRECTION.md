# 耳机校正

耳机校正沿用 ECHO 的独立原生校正链，与个人 EQ 分开启用、旁路和保存。入口在 DSP → 耳机校正。

- 通过生产商 → 型号 → 校正来源浏览，也可按品牌和型号组合搜索。品牌、型号和来源均按 30 项分页，Control 只持有当前页。
- 首次打开只检查本地目录；点击「刷新库」才从既有 OPRA 镜像更新。Core 流式建立 SQLite 索引，完成后替换旧索引。收藏与最近使用保存在 Core 的 DSP 资源库，刷新目录不覆盖它们，各自最多 100 项。
- 选择来源只预览，原始曲线和听感调整在 Core 映射；图表包含各自前级，听感模式用虚线对照作者曲线。点击「载入并试听」才提交音频参数；「应用调整」保存到现有 Core 播放恢复状态。
- 作者原始曲线和听感曲线分别保留。手动前级不改写来源；「还原」恢复当前已载入模式的来源值。高于来源默认值的增益提升先显示确认，拒绝时不提交。确认只在当前曲线编辑期间有效，切换来源、模式、还原或重新读取状态后撤销。
- Core 在播放命令通道内保留来源、模式及两条来源曲线，独立宿主只接收执行参数。宿主回执必须完整匹配频段数量、开关、频率、增益、Q、滤波器及前级；参数被截断或改写时报告失败并旁路，不能伪装成功。Core 检查点和宿主重建恢复这组已确认参数。
- 关闭模块仅旁路校正，保留来源；「清除校正选择」旁路并清除来源，应用后持久化。个人 EQ 和媒体文件不受这些动作影响。校正是 DSP 处理，不属于 Bit-perfect 输出。
