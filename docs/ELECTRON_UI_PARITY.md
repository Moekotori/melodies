# Electron 界面对齐记录

2026-10-09，依据本地 Electron 源码及用户打开的实际 ECHO 开始对齐。目标是延续现有外观和交互。

## 本轮依据

旧版 `src/renderer/styles/theme-classic-colors.css`、`sidebar-surface.css`、`sidebar-selection.css`、`sidebar-entry-controls.css`、`player-bar-polish.css`、`home-editorial.css`，以及 `components/layout/Sidebar.tsx`、`AppTitleBar.tsx`、`pages/HomePage.tsx`。

实际首页、曲目、专辑、设置截图保存在 Git 忽略的 `misc/electron-parity/electron-*.png`。Electron 截图为 2 倍密度，首页归一为 1306×720 进行对照；真实 macOS Avalonia 修正图为 `misc/electron-parity/native-fixed.png`。

## 已对齐的公共区域

- ECHO 应用标识；新配置默认使用已随项目提供的 Outfit，保留已保存的用户字体。
- 经典主题默认配色跟随旧版最终 CSS，包括侧栏和内容的共同底色；保留自定义主题和壁纸的资源所有权。
- 侧栏顶部搜索与 F4 提示；主页独立固定；中间分组可滚动；设置固定底部。
- 选中导航使用文字与图标颜色和字重；普通分组移除横线。
- 标题栏直接访问已有音频、歌词设置抽屉。
- 桌面底栏封面 84px、左侧留白 14px；播放/暂停使用已迁入的旧版分层资源。

## 实际窗口布局修正

旧缩放容器会在内容期望高度超过可用高度时用整个期望尺寸替换窗口尺寸，然后居中。结果是横向空白和纵向裁切。`Controls/UiScaleViewport.cs` 仅处理应用已有的正向 X/Y 缩放，按窗口可用尺寸测量和排列，保留缩放、覆盖层及窗口资源释放路径；其他变换继续交由原容器处理。

主页在资料库中重复出现的问题通过有界导航集合的展示投影修正；仍由同一批 NavigationItem 持有选中、隐藏和顺序状态，集合变动刷新投影，窗口释放时解除订阅。
