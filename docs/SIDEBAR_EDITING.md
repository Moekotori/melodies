# 侧栏排序与显示

2026-10-02。对照用户提供的两张侧栏参考图，使用当前 Avalonia 原生控件、主题与中英文资源。

入口：侧栏任意位置右键 → “排序与显示”。编辑栏提供退出按钮，Esc 也可退出。左侧手柄支持组内拖动和 Alt+↑/↓，目标行高亮；拖到上下边缘按指针事件滚动。眼睛切换显示/隐藏，隐藏项编辑时仍可恢复，退出后移除导航显示。编辑行点击不切页，设置固定入口在退出后恢复。右键“恢复默认侧栏”恢复默认排序和全部显示。

默认导航顺序对齐参考图中的已实现项目；本应用没有 Audio CD 路由，未生成无消费者入口。折叠侧栏进入编辑时临时显示文字和完整宽度，退出后恢复图标模式。自动隐藏抽屉编辑期间不因鼠标离开收起。

职责：`ShellSidebarEditing` 持有窗口局部编辑状态和有界导航顺序；`NavigationItem` 持有行显示状态；`Sidebar` 处理原生输入、捕获释放、焦点恢复和视觉反馈；`SidebarHost` 处理抽屉与 Esc；`WindowPreferencesBinding` 将布局接到现有独立设置 store 的容量 1 单工作器。没有新数据库、文件读取、后台定时器或音频操作。

偏好：`SidebarLayoutPreferences` 保存稳定 ID 顺序与隐藏 ID，旧设置缺字段使用默认。恢复最多处理 64 个 ID，忽略未知、重复 ID，保留后来新增的导航项目。编辑模式不持久化。拖动结束才更新集合和保存，取消捕获、离开编辑或视图脱离均释放输入状态与订阅。

验证：`tools/Echo.SidebarPreview` 使用产品控件进行原生右键/Enter、眼睛、组内拖动/跨组拒绝、键盘移动、退出/Esc、图标模式恢复、默认恢复和真实 JSON 读回，生成明暗/英文 PNG。证据在 `misc/sidebar-edit/`，本轮构建/失败重跑/短测累计约 89 秒。桌面定向编译复用本轮已编译依赖；整树构建曾被并行 `SelectedFileDiscovery` 的 `OsuFolderExpansion.Collect` 参数错误阻塞，未修改该扫描代码。短测和 Headless PNG 不代表运行中应用或三平台实机验收。

回滚：右键恢复默认即可恢复布局；移除新增布局字段仍兼容旧设置。旧工作区和生产数据库不参与。
