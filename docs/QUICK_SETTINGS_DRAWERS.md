# 右上角音频与歌词设置抽屉

2026-10-02。这里的“侧栏抽屉”指原版右上角耳机和歌词图标打开的右侧设置，与左侧导航自动隐藏分开。

## 已接通的用户路径

右上角两个图标现在打开右侧抽屉，不再跳到音频占位页或歌词页面。歌词独立舞台中的耳机/设置按钮也打开同一个抽屉。一次只展示一个设置视图；关闭按钮、Esc、遮罩点击、页面导航和窗口隐藏都会收口。打开时焦点进入抽屉，Tab 在面板内循环，关闭恢复原焦点。音频 440 DIP、歌词 460 DIP，窄视口限制为可用宽度减 12 DIP；内容滚动，音频设置分类保留紧凑应用按钮。

| 面板 | 实际入口与行为 |
| --- | --- |
| 音频 · 输出 | 原生宿主返回的模式、当前模式下的设备、系统默认输出、刷新、当前输出摘要 |
| 音频 · 设置 | 采样率、缓冲、PCM/DoP/Native DSD-SDM、ASIO 声道与起点、DSD 能力探测、EQ、交叉馈送、播放速度；点击应用发送实际会话命令 |
| 音频 · 诊断 | 实际信号路径、可选中文字、复制、重试播放、恢复普通输出与音效默认值 |
| 歌词 | 12 种既有样式、Afterglow 外观、字号、辅助文字字号、字体、对齐、逐字高亮、上下文、译文、罗马音、时间偏移、恢复默认、打开歌词页；修改共享显示状态并经既有 store 保存 |

输出和 DSD 选择仍遵循宿主/驱动能力，不能以请求参数代替实际输出。DSD 控件只有在已启用的输出模式支持时提供对应选项。原生高级 DSP 由新桌面 Bootstrap 启用 `allowProDsp` 控制入口，EQ/交叉馈送默认关闭、速度默认 1，不默认开启额外处理。C++ 实现和旧 ECHO 均未修改。

## 职责与资源

- `ShellQuickSettings.cs`：窗口局部打开种类、标题和入口命令，关闭队列/左侧导航抽屉以避免叠层冲突；不拥有音频或曲库事实。
- `QuickSettingsDrawer`：窗口根层覆盖与有限 MotionLane；打开时创建一种内容，关闭退场后释放。退场立即停用输入，快速反向取最新 generation，隐藏立即结束动画并关闭；脱离时取消动画、释放内容并解除窗口、VM 和动效订阅。根层独立于普通页面和歌词舞台，界面缩放共享现有变换。
- `AudioSettingsDrawerView`：使用 Player 所有的同一个音频设置 VM；关闭取消设备查询/刷新，不取消用户已开始的写入命令。`PlayerAudioSettingsViewModel` 使用最新请求版本和至多一个设备查询 token，拒绝迟到结果；绑定列表短暂清空不会发起错误模式切换。应用前取稳定 DSP 参数，应用期间冻结输入，失败通过状态文字显示。Player 释放时也取消读取。
- `GetRetainedDspRequestAsync`：通过既有会话 owner lane 读取一项已确认的 bandless DSP 请求，复用至多 128 项的恢复状态。速度重建/重新打开时读回，无需把队列或曲库导出给 UI。
- 歌词显示及持久化继续由既有 LyricsAppearance/LocalLyricsPreferencesStore 所有。没有第二份显示设置、歌词文档缓存、扫描或数据库写入 owner。

增量限于一个覆盖层、一种可见设置内容、有限动效和查询取消状态。关闭时不保留设置视图，不新增后台计时器、波形绘制或设备轮询。普通 UI 不做同步 I/O。

## 验证与未完成边界

定向工具入口：`Echo.Preview --quick-settings misc/quick-settings-drawers`。本轮包括失败修正的构建/测试累计约 73 秒，每条设置超时，只停止自身进程；没有打包、全量或长时测试。

实际原生宿主短测读回了 44100 Hz/512 帧配置、启用 EQ 与交叉馈送、1.25 倍速度的已确认请求；全新设置 VM 能读回，恢复默认返回 48000 Hz 并关闭 EQ。Headless 原生鼠标按钮/绑定、Esc/遮罩、焦点、快速反向、完整/减少/关闭动画、隐藏恢复、歌词独立舞台和 800 宽/150% 缩放检查通过。歌词样式、42 字号、关闭译文、300 ms 偏移的界面改动经过真实 JSON 写入/读取往返验证。生成原生 Skia 明暗、歌词舞台和窄视口 PNG。

并行的艺术家页面、播放器装配、osu 扫描和本地化修改曾多次阻塞整桌面构建。最终整工作区重建记录见 `misc/quick-settings-drawers/final-build.log`：osu parser 局部变量冲突。定向验证使用 `misc/quick-settings-drawers/snapshot` 和 `runner`：抽屉、设置 VM、入口源码与本次生产修改一致；隔离未完成艺术家页/启动装配，在快照中修正专辑构造冲突和无效格式字符串，修改只发生在 misc。快照将新 Bootstrap 的高级 DSP 开关以相同 native 参数装配。定向源码构建/运行通过不等于当前整工作区已经可启动。

ASIO/独占/KS/DSD 的硬件输出、实际播放听感、Windows 实机输入、帧率、长期资源和其他平台仍未验收。原版 HQPlayer、DLNA/AirPlay 接管、隐藏设备持久化、自动输出策略、完整音频保护策略、桌面歌词、在线匹配及其他背景工具尚未全部迁入；本页不能作为原版所有抽屉功能等价完成的声明。
