## 用户行为与迁移来源

- 主背景可选择、替换、停用和移除；支持本地图片以及静音循环视频。停用保留路径和效果，重新选择同一文件可重试失败读取。
- 支持填满、完整显示、拉伸、平铺、居中；填满和完整显示支持缩放、水平/垂直位置。竖屏背景有独立适配和位置，窗口高于宽时切换，未设置时沿用主背景。
- 迁入旧 ECHO 的十一组背景效果参数；可单独调整背景不透明度、模糊、亮度和界面不透明度。统一透明度作用于页面、顶栏、侧栏和播放栏；可读性保护保持最低 36% 的界面背景。
- 视频智能暂停响应失焦；最小化/持续播放选项响应窗口可见性。关闭或减少动态效果，以及隐藏/最小化主窗口，都会暂停视频并保留最后一帧。停用、换素材和释放窗口取消解码。
- 成功加载后才应用背景界面透明度；读取失败恢复普通实色配色，保留选择以便替换或重试。

对照来源为旧工作区只读文件 `src/renderer/pages/settings/appearance/AppWallpaperSettings.tsx`、`wallpaperSettingsModel.ts`、`src/renderer/app/appWallpaperPresentation.ts` 和 `AppLayout.tsx`。适配使用原生 Avalonia 绘制；亮度采用现有明暗覆盖绘制，不宣称与 CSS brightness 逐像素相同。图片定位沿用新项目的百分比边缘定位，未迁入旧版拖拽裁剪弹窗。

## 职责、资源和回滚

`ThemeBackgroundSettings` 管入口与局部控件；`ThemeWallpaperState` 管效果预设、重试请求和借用预览。`ThemeWallpaper` 是窗口图片/视频帧的唯一资源 owner；预览借用同一位图，不另建解码器。`WindowThemeBinding` 管加载成功后的资源配色与订阅。配置沿用 `ThemePreferences` / `AppearancePreferences` 和既有单工作器设置保存，不增加配置文件或数据库 owner。

图片编码上限 16 MiB，单边 8192、原图 1600 万像素，解码长边最多 1920。视频沿用本次工作区已有的独立 `AppearanceMediaDecoder`：最多 960 长边、15 fps、一个帧缓冲和一次 UI 回执；一工作器、一条最新待处理请求。取消旧请求并校验 revision，避免迟到图片重新出现。离开外观页保留窗口背景；停用或释放主窗口清除背景与借用预览。媒体解码与音频播放宿主独立。

回滚可撤销本模块的外观展示/配色接线，或在外观中停用背景；原配置与普通播放器保持可用。旧 ECHO 工作区、旧生产数据库和原生音频代码未被本改动写入。
