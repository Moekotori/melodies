# 歌词页底栏与迷你底栏

日期：2026-10-02。旧工作区只读对照 `AppLayout.tsx`、`lyricsMiniPlayerAutoHide.ts` 与 `lyrics-mini-player-polish.css`。保留展开、鼠标离开后仅进度、离开唤出区域后隐藏的交互；完整 / 迷你模式与两项离开行为可以独立选择。

## 当前能力

- 完整底栏采用宽幅三列布局；迷你底栏限制在 880px，底部悬浮；闲置进度条宽度上限 340px。均随当前舞台明暗保持可读。
- 显示当前歌曲、艺术家和共享封面；播放、前后切歌、四种顺序、曲库喜欢、进度、音量与队列继续使用已有 owner。队列抽屉在歌词全客户区宿主内实际显示。
- 底栏右侧切换完整 / 迷你；歌词设置抽屉中调整迷你模式、鼠标离开仅进度、播放时自动隐藏。通过原有容量 1 的设置写入队列持久化，旧设置文件缺少新字段时采用默认值。
- 鼠标移到下方唤出区域恢复显示；暂停、键盘焦点、拖动和打开弹层 / 抽屉时保持可操作。舞台空白区域接收指针输入。收起 / 展开使用有限 160ms 淡入淡出，关闭动效时立即切换；隐藏和退出取消闲置计时。
- 窄窗口缩小封面并收起次要信息 / 控制，主要播放、进度、音量、队列与底栏模式仍可用。播放错误在底栏上方显示。

没有引入实时背景模糊、静态假波形、额外播放时钟、图片读取器或曲库连接。此范围不包括独立迷你窗口、自定义底栏颜色 / 透明度、可录制的隐藏快捷键、睡眠计时等旧版高级能力。

## 职责与生命周期

`LyricsTransportView` 负责两种布局、仅进度状态、有限过渡与现有播放命令。`LyricsTransportStyles` 管局部舞台语义颜色、三像素进度线和按钮状态。封面直接使用 `LyricsViewModel.Cover` 的现有一个租约，不再解码。

`LyricsView.Chrome` 只持有一个可取消闲置计时，检查窗口、播放、焦点与弹层状态；脱离时撤销事件和计时。`PlayerSliderInteraction` 持有一次局部拖动预览，松手 / 调节键释放提交一次，曲目或 operation 改变拒绝提交，失焦 / detach 取消。事实 owner 仍是原有播放会话，喜欢沿用原有唯一库 writer。
