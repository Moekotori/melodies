- 胶囊展开约 340ms、收起约 280ms，反向时采样当前呈现值与速度，用已有的有界动量曲线连续衔接；短距离按剩余距离缩短时长。内容 120ms 淡出，小进度 190ms 淡入，隐藏使用 260ms 淡出 / 8px 下移 / 1.5% 缩放。共享裁切几何随胶囊更新，收缩时图标不会露在背景外；不重排整个舞台。
- 暂停、键盘焦点、拖动与弹层 / 抽屉打开时保持展开。鼠标点击留下的焦点不锁住底栏；完整与迷你宽度模式均支持距离收起。减少动态保留短淡入淡出并关闭尺寸 / 位移动画，关闭动效则直接到达终态；隐藏窗口和 detach 取消等待与过渡。
- 窄窗口缩小封面并收起次要信息 / 控制，主要播放、进度、音量、队列与底栏模式仍可用。播放错误在底栏上方显示。

没有引入实时背景模糊、静态假波形、额外播放时钟、图片读取器或曲库连接。此范围不包括独立迷你窗口、自定义底栏颜色 / 透明度、可录制的隐藏快捷键、睡眠计时等旧版高级能力。

## 职责与生命周期

`LyricsTransportView` 负责两种单行布局、仅进度状态、有限过渡与现有播放命令。`LyricsTransportStyles` 管局部暖黑 / 白灰 / 紫色语义资源、六像素进度线和按钮状态。底栏不再持有或绘制封面；歌词舞台继续使用原有封面租约。

`LyricsPlayerVisibility` 是底栏显示状态的唯一 owner：一个指针位置、最多一个边界等待，不因每次远处移动延后或堆叠计时；更早的距离目标可以替换播放反馈等待。`LyricsView.Chrome` 负责接入指针 / 键盘 / 窗口与头部角落的独立闲置计时。`LyricsPlayerSurface` 只绘制一个可变圆角矩形；`LyricsTransportView.Motion` 拥有有限过渡和一个复用内容裁切几何。脱离时撤销事件、等待与过渡。`PlayerSliderInteraction` 仍只持有一次局部拖动预览，播放与曲库 owner 未改变。
