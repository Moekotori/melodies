日期：2026-10-02。入口：侧栏 → 网盘 / 远程。对照旧 ECHO 的来源管理与文件浏览流程，交付 WebDAV 浏览和播放；旧工作区与生产数据库只作参考。

## 视觉重做（2026-10-02）

按用户对第一版界面的反馈重新设计整个页面。来源切换收进顶栏，文件列表使用完整内容宽度；同一行放目录面包屑、搜索与刷新，全部文件 / 音频采用轻量分段切换。文件夹与音乐文件有独立图标和文字层级，播放 / 加入队列在悬停、选择和键盘聚焦时出现。来源编辑 / 移除进入真实菜单。

首次连接页与账号表单拆成独立原生控件，保留现有功能。表单打开聚焦地址，循环 Tab，Esc 关闭并恢复入口焦点；保存后自动浏览首个来源。窄窗口隐藏来源地址及次要列，保持搜索和操作可用。所有颜色继续绑定现有主题，未引入图片缓存、计时器、数据库写入或新的后台 owner。面包屑最多五项，文件行仍只有当前页最多 200 个 DTO。

最新页面 / 样式 / ViewModel 与验证副本逐文件一致。原生明暗、连接表单、菜单、文件行操作、首次连接、900 DIP 中文与 800 DIP 英文截图在 `misc/remote-design/final/`。定向编译和 43 项检查通过，包括原生来源选择、菜单绑定、分段按钮、行内播放 / 队列、搜索回车、面包屑、焦点、Esc、窄窗口及原有边界；累计构建 / 检查约 92 秒。

首轮完整依赖树构建通过，最后整树被并行文件夹模块尚未实现的 `IFolderWorkbench` 成员阻断。最终验证复制当前 Desktop 源码，并引用本轮首个成功构建的固定依赖；副本仅修改项目引用和去掉未使用的原生 Host 复制项，产品源码保持一致。账号、HTTP 与音频仍为内存夹具；当前用户窗口、真实网盘和真实听感不在这次视觉验收内。没有修改并行文件夹实现或结束运行中的应用。

## 当前能力

- 添加、编辑、测试并保存、移除来源；失败保留配置，保存后自动浏览。
- 根目录和子目录、上一级、当前目录名称搜索、音频筛选、200 项分页、虚拟化文件行、刷新和取消。
- 双击 / Enter 打开文件夹或播放歌曲；播放与加入队列复用现有 `PlaybackSessionCoordinator`。
- 中文 / 英文、明暗主题、空状态、连接错误、窄窗口列收缩与原生页面预览。
- HTTP / HTTPS，匿名或 Basic 认证 / 应用密码。地址要求最终 WebDAV 目录 URL，不自动跟随重定向。

## 职责与所有权

| 模块 | 输入 / 输出和资源 |
| --- | --- |
| Contracts/Remote | 来源、文件和分页 DTO；存储、文件访问端口 |
| Application/RemoteSourceCatalog | 最多 16 个来源；一个串行修改 lane，测试和保存回执完成后才发布；不写本地曲库 |
| Infrastructure/WebDavFileClient | 两个并发请求，15 秒总超时，8 MiB XML / 20,000 响应项上限；逐项解析、过滤和排序在后台，只返回 200 项 |
| Desktop/ProtectedRemoteConnectionStore | 接现有系统凭据保护，独立 `credentials/remote-sources.dat`；编码后资料最多 28,000 字节；仅 catalog 调用写入 |
| Desktop/RemoteViewModel | 当前页 200 个行模型、有限来源摘要；每页最多一个前台请求；generation、取消、语言订阅和离页释放 |
| RemotePlayback | 稳定曲目 ID 和独立队列项 ID；鉴权 header 仅进入既有音频接口；既有 checkpoint 排除带 header 的音源 |
| Bootstrap | 只在窗口装配文件服务，在退出时释放；不新增音频、数据库或扫描 owner |

列表页不持有整个目录。每次翻页由文件服务重新读取有界目录，因此超大目录应使用更小的子目录。内存上限是上述协议 / 条数预算，尚无完整进程内存实测。页面失败或取消保留原目录、页号和对应数据，迟到结果不能覆盖新请求。凭据文件保护沿用现有 Windows 实现；macOS / Linux 的系统安全存储尚未接入，不降级明文保存。
