# 详情按钮与排序细节修正

日期：2026-10-02。用户明确指出专辑收藏/更多按钮和排序入口的视觉问题。

已修正：

- 收藏、评分、更多统一为已有 GlyphIcon 系统的矢量图标，修复字体字符形状、大小和颜色不统一的问题；收藏及评分选中使用主题强调色。
- 艺人/专辑详情使用同一紧凑文字排序入口；排序字段、升降序及当前选中勾在一个菜单中，不再使用默认 ComboBox 和亮蓝 ToggleButton。中英资源随窗口切换，资源订阅和菜单在脱离时释放。
- 实际鼠标点击曲目收藏此前被 Handled 阻断了 Button 的命令执行；改为在子按钮处理器中明确执行一次命令，再阻止事件冒泡到播放行。参考 [Avalonia Button.OnClick](https://github.com/AvaloniaUI/Avalonia/blob/master/src/Avalonia.Controls/Button.cs)。
- 窄窗口保留评分与事实区，移到头部下方；标题按旧版视觉宽度规则缩放，艺术家链接允许换行。头部图像按需使用现有 640 px 缓存入口。
- 封面点击预览、关闭及 Esc 恢复焦点，复用封面图片租约，不另外解码大图。
- 播放/加载按钮状态更明确；移除播放标题的局部颜色覆盖。截图审查后还移除了行播放图标的局部 Opacity 覆盖，让 hover/播放状态样式能够生效。
