# 流派墙与详情迁移

日期：2026-10-02。

## 能力与来源

流派已加入资料库侧栏、搜索焦点快捷键和真实页面路由。页面提供圆形本地封面、首尾字母缺图回退、流派及歌曲/专辑计数、120 ms 防抖搜索、回车立即提交、名称/歌曲数量/专辑数量双向排序、刷新、空结果和重试。排序记入现有桌面偏好。窄窗口把搜索和选项分成两行。

详情默认显示专辑，使用最多四份现有封面租约拼图；专辑可进入既有详情并返回流派。曲目页复用紧凑行、喜欢、分页、音质/名称/时长排序、单曲播放、下一首与入队。流派播放/随机/入队最多取 1000 首，并显示截断提示。

只读对照旧工作区 `GenresPage.tsx`、`GenreDetailView.tsx`、`genreKey.ts`、`localGenreAggregationSql.ts` 和用户截图。NFKC/trim/大小写归一、空标签未分类、完整标签语义均沿用；`Pop/Rock` 不拆成两个标签。显示名采用出现次数最多的标签写法，同次数按名称确定。旧侧栏图标资产已复制到新项目。

筛选弹层中的网盘选项当前不可用：新工作区尚未提供远程曲库查询契约。原版随机流派顺序、远程音源和完整旧版播放选择策略不在本次交付范围。封面来自当前本地曲目/专辑，不是内置假图。

## 职责、所有权与边界

- `GenreModels`：有界查询和流派/曲目/专辑关系契约。
- `GenreSchema`：新库 v13 派生索引；升级前经 SQLite backup 保存一致快照。扫描插入、重新标记、专辑移组、missing、恢复和删除在原 writer 的事务中更新计数。之后的 v14/v15 是并行历史/专辑模块迁移，保留其顺序。
- `GenreQueries`：interactive lane 的只读事务、SQL interrupt 取消、revision 校验、最大 200 行分页；流派计数缓存最多 16 项。专辑关系进入原 `AlbumQueries` 的有界筛选，并纳入数量/随机 pivot 缓存键。
- `GenresViewModel` / `GenreWallViewport`：当前视口加前后各一行、最多 12 列；最多三页（600 项）DTO、24 个回收控件，按 generation 丢弃迟到结果。没有整库 UI 集合。
- `GenreCard` / `GenreDetailView`：共用既有 32 MiB、192 条封面缓存和工作器。离屏、隐藏、详情覆盖及页面释放取消图片请求、清空控件、归还租约。详情只保留当前 200 首、三页专辑和最多四张拼图。
- `GenreDetailViewModel`：调用现有播放会话 owner，无原生音频协议或设备实现变化。导航取消读取；播放状态订阅在释放时解除。历史导航仍使用最多 16 项 DTO 的 `DetailNavigator`。

UI 不打开数据库，不同步读文件或解码。新库检查仍拒绝旧 ECHO 生产格式；本次没有打开旧生产库写入。

## 短验证与局限

执行累计约 **114 秒**，单条最长约 17 秒，未打包或跑全量测试；仅停止自己启动的超时构建。日志和截图均在 `misc/genres-migration/`。

隔离 SQLite 夹具通过：651 个流派、200 行稳定分页、全角/大小写合并、未分类、斜线完整标签、LIKE 字面转义、专辑与曲目计数、retag/专辑移组、missing/恢复、取消、revision 拒绝、v12 到 v13 备份/回填。首次组合测试在 UI 模拟播放处失败，原因是夹具未创建音频路径，以上数据库断言此前均已通过。

补齐夹具音频文件后 UI-only 重跑通过：真实 Avalonia/Skia 控件、明暗截图、搜索覆盖/空状态、End 深页焦点、隐藏恢复、流派→专辑→流派、200/42 首分页、模拟播放、下一首与整流派入队、中英文切换、800 px 窄窗口及退出资源清理。最终视觉修正后再次通过，截图见 `preview/genres-light.png`、`genres-dark.png`、`genres-narrow.png`、`genre-detail-dark.png`、`genre-tracks-dark.png`。

**构建范围**：共享源码当时受并行托盘、歌单、历史、首页歌词和播放器装配未完成代码影响。为完成定向验证，使用 `misc/genres-migration/snapshot/` 源码快照：只在快照中修正歌单源生成属性引用、首页歌词解析参数、播放器构造参数，排除未完成历史 UI 与其他 Preview smoke，不复制原生运行时。流派业务/页面保持本次源码实现。最终桌面快照构建 0 错误、5 个既有运行时 XAML loader 警告，定向 Preview 构建 0 警告/0 错误。不能把它表述为当前整个工作区构建已通过。

预览使用隔离数据和已有本地 SMTC 封面缓存的只读副本，名称/图片配对与数量为测试夹具；未读取旧生产库。快照的首次语言资源缺少标题键，预览临时注入标题；最终快照编译已加入真实标题资源，本次源码同时加入中英标题键。音频响应为模拟，尚未验收真实设备、跨平台交互或大库 Release 性能。

可复跑入口：`dotnet run --project tools/Echo.Preview -- --genres misc/genres-migration/new-preview [封面目录]`。共享代码可编译时使用；现有定向入口支持 `ECHO_GENRE_UI_ONLY=1` 复用明确输出目录内的夹具。默认会新建隔离数据库，不使用用户曲库。

## 回滚

移除流派侧栏/路由和新页面装配即可停用。已升级新库的派生表可以保留，无额外常驻进程；禁止把 `user_version` 向下改或以旧 schema 写入。需回退数据库时只恢复明确选定的新库升级快照，旧生产库无关。
