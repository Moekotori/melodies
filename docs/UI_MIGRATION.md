# UI 迁移与视觉对照

日期：2026-10-02。目标是复现旧 ECHO 的实际界面；本阶段先处理桌面框架与首页，不表示全部页面或全部功能迁移完成。

## 对照依据

旧工作区 `D:\ECHO` 只读。用已有 `out/renderer` 在本机浏览器渲染，首页无曲库、未播放、Classic 主题；从实际 DOM 读取最终生效尺寸与样式。浏览器没有 Electron 桥接，所以版本、授权、设备和生产曲库状态不作为功能对照依据。

不能只翻译 `tokens.css`：`theme-classic-colors.css`、`album-placeholder.css`、首页 editorial 和 player polish 等后加载样式决定最终效果。第一版误用了基础渐变、音符占位与 Avalonia 默认按钮布局，已经据此修正。

1440×900 同状态对照：标题栏 40，侧栏 220，播放器 108；首页起点约 (274,76)，封面 280×280，正文起点 x=580；统计块 y=399、高96、间隔16；发现区 y=517，右栏232、列距32；播放栏封面84，中央列约691。中文字体为 Microsoft YaHei，西文沿用原版 Outfit。

## 实现边界

- `Shell`：标题栏、分组导航、折叠、主题切换、当前页面；VM 不拥有曲库或音频事实。
- `Features/Home`：原版空状态、统计入口、最近活动、推荐和聆听概览。后续真实数据进入局部 VM，不复制整库。
- `Features/Player`：与同时进行的播放迁移保留绑定、命令、文件选择、队列、音量和输出入口；普通界面布局向旧版对齐。尚未迁入的封面数据使用同一主题吉祥物占位。
- `Controls`：原版双色 PNG/SVG mask、原版 Lucide 图形、静态热力图和空闲波形装饰。空闲波形不是音频采样。
- `Resources/Themes`：基础语义资源加最终 Classic 覆盖；未声称其余主题已完成。
- `tools/Echo.Preview`：仅开发工具使用 Avalonia Headless + Skia，输出原生控件 PNG，不是 HTML 重画；正式应用不加载此工具。
  预览关闭播放记录恢复和系统媒体服务；截图前关闭局部过渡以取得稳定颜色，动画由独立短检查覆盖。正常启动维持原有默认行为。

图标实例最多持有两张64px mask，脱离视觉树释放；字形几何同实例释放。字体与两张主题占位图由应用资源持有至进程退出。静态页面没有新增定时器或动画工作器。取消和播放生命周期由对应模块管理。

## 进度与验收

- 已建立可编译运行的桌面项目、锁定 SDK 与 NuGet 包、默认编译绑定。
- 已修正 Classic 最终颜色、吉祥物封面、统计块拉伸、侧栏默认分组、禁用控件背景、文字字号及播放栏比例。
- 已完成第一次原生明暗渲染和导航/主题/标签/折叠短检查；上述视觉修正后重新生成对照图。
- 已迁移设置页主体、十三分类的基础控件与可用偏好的保存恢复；具体功能矩阵和视觉依据见 `SETTINGS_MIGRATION.md`。
- 全页一比一验收仍待完成：有曲库与播放状态、首页下半区、曲库详情、设置、歌词、抽屉、自定义主题与窄窗口。占位页面明确显示迁移状态。
- Windows 原生窗口操作与实际播放另行验收，静态 PNG 不能证明设备或三平台一致。

构建每条最多60秒，本轮验证累计120秒内；失败只修必要处，不跑长测试或完整打包。旧 ECHO 保留，新应用与生产曲库隔离，可直接停止新应用回退旧版。

依赖核对：[Avalonia 12.1.3](https://www.nuget.org/packages/Avalonia/12.1.3)、[MVVM Toolkit 8.4.2](https://www.nuget.org/packages/CommunityToolkit.Mvvm/8.4.2)。
