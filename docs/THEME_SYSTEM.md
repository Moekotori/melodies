# 原生主题系统

日期：2026-10-02。入口：设置 → 外观。

经典浅深色以旧版最终加载的 `theme-classic-colors.css` 和已有 `EchoClassicTokens.axaml` 为依据。49 个内置项保留旧版编辑器的配色数据和预设 ID；它们是原生配色预设，不代表旧 CSS 皮肤装饰、动画的逐像素复现。

## 已实现

- 浅色、深色、系统、氛围和亚克力入口。氛围保持旧版深色语义；定时支持跨午夜与反色，隐藏/最小化停止计时，激活后校准。
- 原版 26 项颜色与八项材质/动效参数，浅深色独立编辑、各预设修改保留、HEX/RGBA、单项重置、对比度提示、随机配色及最近 16 次撤销。
- 最多 16 个自定义主题，支持另存、应用、改名、删除；导入原版 `echo.custom-theme` v2 / `echo.theme-preset` v1 配色，导出原版 v2 平面字段。非法导入不提交，文件最大 64 KiB。
- 本地背景、透明度、模糊、填充/适应/拉伸、水平/垂直位置；主/中文/备用字体名称。
- 亚克力与浅深色组合，透明度、失焦保持、实际平台状态和实色降级。主题动效保留原版 0.12–8 秒范围，默认 0.22 秒，使用可取消的合成动画；减少模式仍限制为短淡入，关闭模式立即更新。

## 职责、边界与释放

`ThemePreferences` 是 UI 无关快照。`ThemeViewModel` 拥有编辑、覆盖与撤销；`ThemeLibrary` 管交换和主题库；预设、字段与颜色算法独立维护，没有数据库或播放事实。

`WindowThemeBinding` 拥有窗口资源、平台订阅与唯一分钟边界计时器；`ThemeResourcePalette` 将设置投影到主壳、设置、列表、播放栏及 Fluent 折叠控件，字体使用动态资源。其他窗口可复用同一投影，本模块不创建额外窗口。

`ThemeWallpaper` 有一个后台解码工作器和一个最新待处理请求。generation 丢弃迟到结果；退出取消读取并释放图像。输入最多 16 MiB，原图最长边 8192 / 1600 万像素，显示图最长边 1920。已经执行的 Skia 同步解码只能完成后丢弃，Token 不会中断它。

偏好复用 `JsonDesktopPreferencesStore` 的单写入 owner、容量一最新快照通道、原子替换和退出冲刷。加入主题库后文件上限改为 512 KiB；保留版本 1 与旧 `IsDark` 读取。不读写旧 ECHO 设置或曲库。

## 界面重做（2026-10-02）

主题入口已重新设计为分段模式、播放器式即时预览、六个常用预设缩略图和带搜索的完整画廊。编辑按配色、材质、背景与字体、主题库切换；颜色使用色块/HEX 与自定义 RGBA 弹层，不再使用旧主题页的折叠表单。

全局基础 ComboBox 使用 EchoSelectors 自绘模板，包含弹层、当前项标记、悬停/键盘焦点、禁用态和可编辑字体输入。图片适配呈现用户可理解的名称。ThemeChoiceList 为横向分组选项提供方向键/Home/End，并在快捷键入口保护编辑焦点。

ThemeScenePreview 只在配色或尺寸变化后绘制；画廊固定最多 49 项，不读取封面或播放状态。窄窗口通过响应式布局调整元素位置，保持圆形与字体比例。切换编辑分类关闭隐藏的选择框；离开页面关闭画廊并解除订阅。

本轮主题源码/XAML 隔离构建零警告、零错误；实际 Headless 鼠标打开、主题搜索/应用、方向键、Enter/Esc、编辑焦点与隐藏弹层清理通过。已输出明暗、画廊/选择框展开与 600 像素视口截图。Desktop 在隔离输出目录完成编译；完整 Echo.Preview 工具受并行 SongDropSmoke 的 IStorageFile/IStorageItem 伪实现编译错误阻塞，不改动该测试。早期完整语言包正在并行更新而读取校验失败，因此定向主题预览使用固定语言夹具，不能据此宣称整个语言系统通过。

## 切换预设后的界面层级修正（2026-10-02）

旧预设的不透明灰色边框会被直接放大为整窗分隔线。现在窗口投影保留边框色相和原透明度，以背景对比度限制装饰边框与分隔线；焦点、强调色、选中状态和保存的原始配色不变。背景第二、第三色只以 22% 混入主背景，缓和冷暖色带；导航辅助文字采用次要文字色，设置导航移除叠加底色。预览同步背景/边框算法，预设列宽向下取整并留一像素余量，避免最后一项因小数尺寸掉行。

验证在 misc/theme-polish/：固定桌面源码副本引用已构建的应用层依赖，移除仅用于音频设备的 native 输出拷贝项。最后源码编译零错误，五项既有无默认构造函数 XAML loader 警告；实际 Avalonia 主壳的陶土蓝/经典/樱粉奶霜明暗与窄窗截图、49 项预设边框对比、原焦点色及自定义 alpha 保留通过。所有构建、失败修复与渲染累计约 115 秒，不进行打包或长测。截图是静态隔离窗口，不代表当前运行应用、音频、系统亚克力或跨平台验收。新增算法只在资源更新时执行，不新增后台任务、数据库或缓存 owner；回滚上述投影和设置展示修改即可。

## 配色编辑精修（2026-10-02）
