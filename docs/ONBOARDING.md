# 新手教程

Control 的首次启动流程对齐 Electron ECHO：语言 → 音频输出 → 外观 → 日常使用 → 确认，之后可进入操作引导。

- 默认在桌面偏好和播放启动设置读取结束后打开；显式完成、跳过或按 Esc 后，使用已有桌面偏好 writer 保存 `onboarding-completed`。重开入口为「设置 → 通用 → 语言与引导」，顶部「更多」也可单独打开操作引导。
- 语言和外观在教程内预览。未改动的设备、高级音频配置、自定义主题和背景保持原值。完成时先等待 Core 播放客户端的输出配置回执，再应用改动的展示偏好和完成标记。失败显示原因并保留草稿；跳过丢弃草稿。
- 引导只导航和高亮真实控件，不自动播放、导入、修改队列或切换歌词样式。没有歌曲或目标控件时仍可继续。所有步骤可返回，Esc 退出；退出恢复原来的可用焦点。
- `OnboardingController` 属于窗口，视图按需创建。设备枚举可取消，最多展示 4 种模式、256 个设备；关闭教程、Ultralight 卸载界面或退出窗口时释放视图、枚举与事件订阅。无后台定时器、曲库副本或音频宿主生命周期所有权。

聚焦验证工具：`dotnet run --project tools/Echo.OnboardingPreview -- misc/onboarding/screenshots`。它使用独立临时曲库、模拟音频回执和真实 Avalonia 渲染，检查草稿保留、失败重试、鼠标/键盘、窗口缩小和引导释放；不代表真实音频设备验证。
