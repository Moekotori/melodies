## 视觉重做（2026-10-02）

针对上一轮“像功能表格、缺少设计层级”的反馈，按真实控件截图重排本地目录页面，保持原有目录/查询/扫描/播放入口。

- 页面标题独立于目录导航，导入和全局刷新放在页头；目录栏使用 208 像素默认宽度、42 像素行高、真实 folder/chevron 图标及完整目录名称提示。窄窗口改为可关闭目录面板。
- 当前目录使用 148 像素封面叠放、34 像素标题、分明的路径与统计层级。播放/队列/随机集中在头部；路径、重扫和管理使用次级工具区。
- 曲目表只保留表头分隔线，58 像素行、44 像素封面、名称/艺术家两级文字，格式/分辨率两行信息；当前曲目有明确反馈，喜欢使用实际矢量图标。标题和时长按其左右对齐边界核对，不把不同文本宽度误判成列错位。
- 封面复用现有 Artwork cache，只有已实现的可见行持有租约，隐藏/释放撤销图片资源。头部最多缓存 3 条样本路径，筛选与搜索不清除目录身份、封面和目录统计。
- 排序选项使用稳定对象和可观察本地化标签，语言变化更新标签而不重设选择或清空曲目多选状态。

设计使用原有语义色和 Outfit/中文 fallback 字体：主体、辅助文字、分隔线和紫色操作各有职责，未给每行增加阴影、卡片或持续动效。静态封面角度用于目录集合的识别，无逐帧布局工作。

## 已接入的本地流程

- 导入根目录、目录按需展开/收起、子目录分页、轻量路径恢复、键盘目录导航、可调目录栏宽度。
- 当前目录与包含子目录切换、搜索、无损筛选、五种排序、升降序、200 首曲目分页。
- 曲目双击/Enter 播放、Ctrl/Shift 多选、右键播放/下一首/队列、选中曲目批量操作、喜欢持久化及当前播放标记。
- 整目录播放、随机播放和加入队列使用当前筛选顺序；最多 1000 首。更大的目录明确提示缩小筛选或选择曲目，不静默截断。CUE 片段范围和 osu! 实际音源通过已有 source 事实传给播放器。
- 导入与重新扫描沿用 `DesktopLibrary.ImportAsync` 的同一扫描/写入 owner；显示真实进度、取消和已提交结果。文件夹打开、路径复制、读取错误和重试提供实际入口。
- 明暗、中英文、小窗口单目录面板；路径文字截断可查看完整提示。页面不包装外层滚动容器，曲目表和目录各自虚拟化。

## 职责与资源

| 位置 | 职责 / 边界 |
| --- | --- |
| Contracts/Library/FolderModels | 小型目录和曲目分页 DTO；查询包含取消、revision 与稳定排序 |
| Infrastructure/Library/FolderQueries | 现有交互读 lane，path_key 索引前缀范围；聚合由 SQLite 执行，不传整库路径给 UI |
| Infrastructure/Library/FolderSchema + ScanJobs | 新格式 schema v9 保存已导入根目录；与 scan_jobs 插入同事务、同 writer。迁移回填尚存的扫描历史 |
| Desktop/Features/Folders/FolderTreeState | 每次 100 个目录；最多 600 个已展开节点、最多 4 个展开请求。容量不足缩小分页，收起取消并移除子分支 |
| FoldersViewModel + FolderPlayback | 当前页最多 200 个 DTO，查询切换取消并丢弃旧 generation。目录批量队列临时最多 1000 项，提交后释放 |
| FoldersView 与 Artwork/Scanning 部分文件 | 文件选择器、扫描展示、布局、最多三个封面租约；复用 32 MiB 共享封面预算。隐藏释放封面，脱离/关闭取消任务并解除订阅 |
| FolderTrackList + FolderColumnsGrid | 原生虚拟化、多选、表头/行共用网格。表头跟随 ScrollViewer viewport，避免滚动条导致列错位；不逐帧扫描视觉树 |

数据库 read lane 支持排队取消和在连接执行期间的 SQLite interrupt。写入取消仍按现有事务/批次确认边界收口，不能撤销已提交曲目。目录树展示已入库内容，不同步枚举磁盘上的所有空目录。

## 迁移范围与回滚

本增量完成本地浏览和播放入口。远程网盘、固定目录/跨目录合并选择、重复项/缺封面等高级洞察、忽略规则管理与旧版完整巡检面板仍单列待迁移；不宣称完整旧版文件夹功能等价。

根目录持久化从 schema v9 开始。历史已经被旧的 32 条扫描记录上限清掉的根目录不能凭空重建原始导入边界，重新导入该目录即可登记。现有曲目不会因此删除。此前保留下来的扫描根在迁移时回填，后续扫描历史清理不再影响目录入口。

旧 ECHO 实现和生产库完全保留。回滚页面接入可移除 folders 路由；已迁移的新格式数据库应保留，新旧应用数据目录继续隔离。不能把 v9 新库交给更低 schema 的旧开发二进制直接打开；需要回退数据库时使用升级前的一致性备份。
