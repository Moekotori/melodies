# 桌面动画系统

日期：2026-10-02。实现属于 `Echo.Desktop/Motion`；系统偏好查询属于 `Echo.Platform/Windows`，由 Bootstrap 装配。只管理界面状态，不接管音频、扫描或数据库。

## 已接入入口

| 入口 | 行为 |
| --- | --- |
| 主窗口首次显示、侧栏导航 | 淡入与小幅垂直移动；快速切换跟随最新页面 |
| 主页最近活动标签 | 旧内容退场、新内容进入，文本身份独立保存 |
| 侧栏展开/收起 | 目标布局一次计算，内容区域用渲染位移衔接 |
| 按钮、播放控制、列表选择 | 短促明暗/按压反馈；播放控制有轻微 hover 缩放 |
| 提示与系统媒体控制错误 | 进入、退出和中途反向；退场文字保持到结束 |
| 播放栏现有弹层 | 打开、关闭和关闭中重新打开；共享所属窗口偏好 |
| 设置 → 外观与动效 | 四种模式、主题开关、页面/封面演示、列表、展开与弹层预览 |

封面演示仅展示界面衔接，不模拟播放事实；真实封面读取尚未在播放器中迁移。其他仍标为迁移中的页面只接入导航过渡。动画选择暂在本次进程运行内生效，尚未接入持久化设置。

## 时长与机制

统一定义在 `MotionTokens`：控件反馈 100 ms，展开/弹层进入 180 ms，页面进入 220 ms，退出 180 ms，减少动态效果时短淡化 80 ms。页面移动 8 px，局部表面移动 5 px；进入柔和减速，退出优先消除旧内容重影。

局部属性反馈使用独立 Transition；页面、提示、侧栏和弹层使用有限 Composition 动画，透明度、平移与缩放在渲染线程插值，不逐帧设置 UI 属性。侧栏布局只计算一次。ToggleSwitch 仅在完整模式中保留局部旋钮过渡。没有无限循环、每帧业务绑定或常驻动画定时器。

2026-10-02 第二轮根据“不够丝滑”的反馈把组合过渡迁入 Composition。新树先完成布局，再在 composition commit 回调中启动动画，避免 UI 属性同步覆盖初始透明度动画。第三轮等待开始批次 Processed，再等待有限动画时长与最终批次 Rendered；遮挡后端的帧确认最多等待 80 ms，超时收敛到合法最终状态，窗口隐藏或取消立即退出等待。提交回调中的模型暂时保持起点，真正提交时才开始计时，避免准备期间读到目标位置而产生跳变。

取消前从局部单调时间轨迹估计当前位置和速度。100 ms 内的反向操作采用有限五次 Hermite 曲线继承速度，终点速度与加速度为零；归一化惯性斜率限制在 -8 至 8，透明度受 0 至 1 的边界约束。当前产品中的平移都是单轴；若未来加入任意二维运动，需要独立处理各轴惯性，不能把当前主轴曲线当成完整二维物理引擎。轨迹只在交互时求值，没有新增 UI 帧循环，亦不是渲染线程位置回读。

`MotionChannel` 为渲染线程复制有内部求解缓存的 SplineEasing，UI 轨迹估计不与渲染线程共享可变缓存。速度估计采样跨度高于框架样条求解精度，避免把正在移动的画面误判为零速度。框架依据：[Avalonia KeySpline 实现](https://github.com/AvaloniaUI/Avalonia/blob/12.1.3/src/Avalonia.Base/Animation/KeySpline.cs)。

退场页保持原来的颜色和控件明暗，通过命中与焦点隔离阻止操作，避免触发整页禁用样式。页面和预览宿主使用语义底色隔开新旧文字；旧页不再反向漂移。参考：[Composition 动画](https://docs.avaloniaui.net/docs/graphics-animation/composition-animations)、[控件过渡](https://docs.avaloniaui.net/docs/graphics-animation/control-transitions)。

## 所有权与释放

| 模块 | 输入/输出与资源上限 | 取消与释放 |
| --- | --- | --- |
| MotionPolicy / MotionScope | 每窗一个偏好对象；不持有视觉树、任务或数据源 | 窗口关闭解除绑定；隐藏/最小化通知当前控件立即收尾 |
| MotionLane / MotionPlayback | 每个局部 owner 最多一个当前 CTS 与一组有限 compositor 动画；输出透明度/变换 | 新请求取消旧时间线及未提交回调；完成或取消处置 CTS，清除局部轨迹与 compositor 动画；最终值预先建立 |
| MotionPresenter | 当前 Control 与最多一个退场 Control | 新导航立即丢弃过期树；退场不接收指针/键盘输入；结束清空旧子树 |
| MotionSurface | 一个保留的局部子树，例如提示或展开说明 | 从当前视觉值反向；退出后不显示；脱离树解除偏好订阅 |
| MotionFlyout | 一个框架 popup presenter，不另建副本 | 保留 Closing 取消语义；退场立即停止输入；隐藏、脱离目标和关闭都取消 |
| MotionFeedback | 仅实例化控件的 Transition；不为整库建状态 | 关闭动画清除 Transition；减少效果清除缩放与旋钮位移；脱离树解除订阅 |

所有页面保留原有有界数据职责；这套系统不缓存导航历史视觉树、图片副本或全库列表。没有动画时不产生独立帧驱动。真实显示节奏依赖 Avalonia 和渲染后端，尚未新增自定义呈现时钟或高刷新率开关。

第三轮增加 `ContentRetired` 释放节点。曲目、搜索、专辑、艺术家、文件夹页面在导航时保留正在退场的封面/行资源，由已有视觉脱离生命周期处置；关闭窗口先收敛退场树，避免退出时资源悬挂。DetailNavigator 接入同一个宿主，详情互跳不再先 Dispose 再替换；其旧详情在退场脱离后处置，历史仍只保留最多 16 个 DTO。资源总量增加至过渡期间的两页，结束回到一页；不是无成本的视觉改动，仍需实机测量图片和 UI 峰值。

队列抽屉采用水平位移，遮罩同步淡出。侧栏和快速设置抽屉在退场时保留控件明暗，通过命中测试和焦点阻断操作。主题时长和装饰强度只计算一次，当前中途姿态不再重复乘强度；真实布局 FLIP、水平抽屉的几何距离保留原值。默认时长不变，显式主题时长最多 600 ms；减少动态效果的淡化仍不超过 80 ms。

默认跟随系统。Windows 通过只读 `SPI_GETCLIENTAREAANIMATION` 查询，在窗口激活时刷新；没有轮询或 UI 磁盘读取。macOS/Linux 的系统偏好暂不可用，界面明确提示并允许手动选择。减少模式保留短淡化；关闭模式直接到达最终状态。

## 最小验证与边界

`tools/Echo.Preview/MotionSmoke.cs` 运行真实 Avalonia 控件与渲染时钟，覆盖快速导航、旧页脱离、退场输入、提示反转、关闭/减少/系统模式、弹层反向和隐藏恢复。`CompositionSmoke` 直接读取 compositor framebuffer：本轮中间帧红色强度 225、顶边 46，最终强度 255、顶边 44，验证透明度与位移确实在合成帧中插值。`MotionFilm` 改用 compositor framebuffer 捕获 184 帧；视频按采样文件的实际时间间隔编码，60 fps 是视频编码设置，不能当成实机呈现帧率证明。

首轮资料在 `misc/motion-verification/`，第二轮在 `misc/motion-smooth/`，不含凭据。定向构建与短测在单条 60 秒、累计 120 秒的预算内完成；并行专辑模块的构建中间状态曾阻塞验证，保留其实现，仅修正同名 Grid 与扫描枚举的解析冲突。最终桌面预览与 compositor 像素检查通过；构建另有专辑 XAML 的既有弃用/加载构造器提醒。已检查浅色和深色原生截图；未完成真实桌面鼠标/键盘验收、长期资源观测、macOS/Linux 或实机呈现帧测量。

回滚可在设置中选择关闭动画；代码级可移除 EchoMotion 样式、还原页面宿主及弹层类型。原音频和数据库 owner 不受动画模块影响。

## 第三轮深入验证（2026-10-02）

`MotionDepthSmoke` 实际驱动 compositor 与真实控件，确认反向时先沿原方向减速再回到新目标、连续提交后取消未提交回调、最多两棵树、退场后恰好处置一次、水平抽屉反向/关闭模式，以及主题强度不会重复缩放中途姿态。最新独立短测中反向起点为 6.46 px，中途继续至 3.28 px，最终到达 40 px；compositor 中间帧红色强度 213、顶边 47，最终为 255、44。数值来自短测夹具，不能外推到真实窗口帧率。

当前日志在 `misc/motion-depth/isolated.out.log`。动画源码与本工作区真实本地化代码通过独立编译及短测，保留所有并行工作。完整桌面验证曾遇到开发进程占用 Debug DLL、平台互操作编译选项及正在迁移的业务接口；最新 Release 尝试停在 `GenreQueries` 对 `QueryAlbumsAsync` 的参数数量不匹配。未因本轮动画修改而终止其他开发进程，也没有把独立模块结果写成整体验收通过。
