# 迷你播放器与桌面歌词迁移

日期：2026-10-02。此文记录实现边界；完整窗口行为短测尚未通过，不能将预览当成实机验收。

## 使用入口

- 主窗口右上角增加迷你播放器、桌面歌词按钮；底栏“更多”也有开关与“悬浮窗口设置”。
- 迷你播放器以封面、曲名、当前歌词/艺术家和播放按钮组成紧凑条；“更多”展开上一首/下一首、进度、音量、队列、返回主窗口和关闭。设置中可置顶、固定位置或切换到迷你播放器并最小化主窗口。
- 桌面歌词为透明窗口，显示当前句及翻译、罗马音或下一句；支持逐词高亮、双行、字体/字号、颜色、透明度、独立偏移和无歌词时隐藏。鼠标进入显示播放、锁定、恢复主窗和关闭工具条，可拖动、缩放。
- Windows 锁定使用原生鼠标穿透；主窗口设置始终有解锁与“重置位置并解锁”。其他平台关闭穿透能力。已有快捷键的 `toggleMiniPlayer`、`toggleDesktopLyrics`、`toggleDesktopLyricsLock` 接入同一状态。

## 来源与归属

只读对照旧工作区 `src/main/app/miniPlayerWindow.ts`、`desktopLyricsWindow.ts`、`src/shared/types/miniPlayer.ts`、`src/shared/constants/miniPlayerGeometry.ts` 和两个 renderer 功能目录；保留紧凑/展开/队列、独立窗口、透明歌词、锁定与位置恢复的基本语义。没有修改旧应用、生产数据库或原生音频。

`Features/Floating/FloatingWindowController` 归主窗口生命周期所有，最多创建两个窗口。两个窗口共用一个 `LyricsViewModel` 与当前歌词选择；迷你播放器独立订阅既有 `PlaybackZone`，共享同一个播放会话 owner，不因主界面释放而失去时钟或队列。命令沿用现有串行通道，进度和音量复用只在操作结束提交一次的交互处理器。

`FloatingPreferences` 是小型设置快照，由现有 JSON 设置单写入工作器保存；没有新增数据库写入者。默认关闭两个窗口，打开时才加载歌词和取得封面租约。关闭最后一个悬浮窗口取消读取并释放模型、字体布局和封面；主应用退出时先关闭窗口，再保存设置和释放播放资源。

## 资源与恢复

- 窗口最多两个，迷你队列继承现有最多 1000 项的有界展示和有限视口虚拟化；不创建整库 DTO。
- 桌面歌词只绘制当前及辅助行；每个字体布局缓存最多 18 条，两个缓存合计约 8 MiB 的估算预算。字体、颜色与辅助文本复用，逐词裁剪不创建逐字控件。
- 桌面歌词只有一个 60/30 fps 上限的帧驱动器；暂停、隐藏、关闭和过期时钟停止连续绘制。主窗口的可见性不直接暂停仍显示的桌面歌词。
- 窗口位置保存用单个 300 ms 合并定时器。恢复时按显示器工作区、缩放和窗口尺寸约束位置；无效坐标回到主窗口所在屏幕，重置忽略保存坐标。显示器变化合并为一条 UI 更新，关闭时解除监听。
- 无歌词隐藏按整份文档是否有文本判断，按文档变更缓存结果，不在每个播放 tick 遍历歌词；前奏/间奏不应误隐藏。
