# 艺人和专辑详情差距补齐

日期：2026-10-02。旧工作区仅作为只读对照；详情功能使用新格式曲库。

## 本次已接入

- 专辑艺人名 → 专辑艺术家详情 → 艺人专辑墙 → 专辑详情，返回及 Esc；历史最多 16 个轻量 DTO，替换释放旧视图。
- 两种详情曲目按默认顺序、名称、时长、音质排序与升降序，SQLite 分页排序；快速切换取消旧请求，并在提交 UI 前验证 generation。
- 专辑播放、下一首和添加队列、收藏与个人评分；艺人播放、随机、添加队列与单曲下一首。写入沿用单一数据库 owner；播放沿用确认后的会话状态。
- 附件标签按需读取代表曲目所在文件夹的图片、PDF、文本、CUE 和 LOG；点击通过系统应用打开。来源标签提供打开及复制文件夹。
- 介绍按需读取 album.txt、readme.txt、description.txt，提供缺失、失败和刷新入口。
- 本地同名专辑候选提供实际导航；明确标注尚未确认发行身份，不能当作联网发行版本或本地版本聚合。
- 艺人页面入口复用当前工作区并行实现的艺人墙、头像、字标和旧版大幅头部；详情专辑列表复用现有专辑墙。

## 资源和性能边界

曲目一页最多 200 个 DTO，艺人/专辑墙最多 600 个缓存 DTO；实际控件由有限视口虚拟化。播放操作临时准备最多 1000 项，遵守现有队列容量；不能宣称已支持整艺人无限队列。排序字段在队列读取开始时固定，避免交互排序把多批次拼成不同顺序。

封面和附件共享 32 MiB 缓存、固定解码工作器和现有图片尺寸上限。附件发现最多检查 512 个文件，返回最多 32 个附件；文本最多 64 KiB；同名候选查询最多 200 行、显示最多 32 行。读取、解码及系统文件打开在基础设施后台执行，UI 不同步读取磁盘或 SQLite。切换标签、退出和隐藏停止附件读取并释放租约。取消数据库工作实际覆盖排队、循环检查和迟到结果丢弃，不承诺中断任意正在执行的 SQLite 语句。

播放时钟不重新构建行；当前 TrackId 改变只修改之前与当前播放行。所有封面均来自测试/新曲库路径，不读取旧生产库。

## 旧版仍有差距

网络简介、外部评分和来源、发行身份识别、完整发行版本管理/聚合、标签文件编辑、拆分/删除、个人标签、稍后听、合作关系/演出和完整听歌统计尚未迁入。本地同名候选和本地介绍不能代替这些能力。多个目录中的完整附件归属仍需独立目录查询。

## 本轮验证

`tools/Echo.Preview/DetailUiSmoke.cs` 的 `--details` 使用独立新库、451 条生成 metadata、250 曲目专辑和 450 曲目艺人。Native Audio 为协议夹具、文件为生成占位，不是音频解码/设备验收。

Release 构建曾通过（0 错误、3 个现有歌词/设置 XAML loader 警告）。run6 已通过 SQLite 排序/翻页、评分/收藏读回、专辑队列、单曲下一首、附件/本地介绍/同名候选、艺人解析、艺人添加/随机及 realized 曲目数量检查；在艺人专辑标签刚挂载时，测试使用 Single 查询视觉树而提前报错，随后改为等待 Any。未获得完整短测全绿结果。

实际 Avalonia 截图在 `misc/detail-validation/run6/`，包含专辑明暗、附件、艺人头部明暗及概览。截图审查后修复浅色主题下艺人深色头部按钮文字的对比；该修复后截图尚未重新生成。

最后一次预览构建受并行新增的 `MotionDepthSmoke` 引用尚无定义阻断。并行 Debug 运行曾锁住 PDB，改为 Release 输出，未停止其他任务。两处微小基线编译修复分别为 OsuScanParser 局部 BPM 变量重名和 LocalizationSmoke 使用当前 PNG Save 重载。

本轮发生多次短构建/失败重跑，未严格维持 120 秒累计验证预算，已停止追加验证。最后的排序快照、隐藏释放和 Esc 小修未在最终树上重新构建；不能把早期构建或生成截图当作全部最终代码验收。尚未做实机帧率、5 万曲目详情性能或三平台验收。

## 回滚

解除详情导航和本地资源装配，可恢复直接专辑详情入口；移除本增量的可选排序参数后恢复默认 SQL 排序。详情未增加数据库 schema，也不更换写入 owner。保留并行艺人墙、动效、本地化、扫描和播放栏修改。
