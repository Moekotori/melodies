# F4 全局搜索迁移

日期：2026-10-02。

对照旧工作区 `src/renderer/components/search/GlobalSearchOverlay.tsx` 与 `styles/global-search-overlay.css`，将主窗口的搜索入口接到原生 Avalonia 浮层。空输入只显示上方居中的宽搜索框；输入后展开结果、数量和操作提示。背景遮罩保留原页面，适配浅色、深色、窗口缩放及歌词独立舞台。

## 职责和使用

- `ShellSearch` 只保存开关状态；右上角搜索按钮、现有 `openGlobalSearch` 动作打开浮层。原曲库搜索页面保留 `search` 路由。
- `MainWindow.Search` 在窗口隧道路由处理无修饰键 F4，输入框内有效，按下状态抑制自动重复；快捷键录制时交给录制器。
- `GlobalSearchOverlay` 管窗口绑定、可取消有限动效、首次布局后的输入聚焦、焦点回交及尺寸；输入职责拆在 `.Input.cs`。
- `GlobalSearchViewModel` 使用已装配曲库查询端口；`GlobalSearchCatalog` 查已有页面与设置定义。歌曲、专辑、艺术家、流派、歌单、设置与页面均有实际打开入口。
- ↑↓ 选择结果，Enter 播放/打开，Esc 或 F4 关闭，点遮罩关闭。设置结果打开并高亮对应设置项。歌曲使用既有播放会话，确认成功后关闭，失败留在浮层并提供重试。

## 所有权和边界

浮层只在打开时创建搜索 VM。一条活跃查询，180 ms 防抖，各曲库类型最多读取 16 行、混合列表最多保留 24 行；设置最多 16 个候选，页面为固定目录。新输入、语言变化、导航、关闭、窗口隐藏及视图脱离取消请求，generation 阻止迟到结果覆盖。关闭清空 DTO、播放动作和焦点引用，窗口生命周期取消事件绑定和有限动效。

查询继续通过新格式数据库的现有有界读通道，不增加写入 owner，不打开旧生产库，不改扫描或原生音频。封面复用现有 `QueueArtwork` 控件和 32 MiB `AlbumArtworkCache`，每个实际行控件持有租约并在脱离时释放。

历史记录、队列条目及文件夹内容尚不作为独立搜索结果类型；可搜索并打开相应页面。旧版搜索缓存、命令面板与所有旧类型尚未等价迁移。未引入整库驻留缓存。

## 验证

`tools/Echo.Preview/GlobalSearchSmoke.cs` 提供 `--global-search` 入口：40 条隔离新格式 SQLite 曲目和一个真实歌单，使用原生 Avalonia Headless 输入及渲染；音频是协议夹具。

本轮完整工作区编译先后遇到并行首页 XAML、历史接口/展示类型、托盘及歌单未完成代码。固定源码快照位于 `misc/global-search/workspace`；快照排除未接入的历史展示文件，修正快照中的歌单字段赋值，并排除无关未完成预览测试及未复制的原生运行时。上述隔离修补不写回生产文件。搜索代码和 XAML 编译通过，快照桌面有五条既有构造函数加载提示；定向预览工具最终构建 0 警告、0 错误。

定向 smoke 通过 F4/长按、自动聚焦、方向键、Esc/外部点击、分页 DTO 上限、快速输入取消、专辑/艺术家详情、歌单曲目、设置高亮、页面导航及播放会话调用。最终一轮 smoke 约 6.1 秒，含失败构建和重跑的整轮进程等待约 111 秒，无单条超过 60 秒。

原生截图：`misc/global-search/empty-light.png`、`results-light.png`、`results-dark.png`、`no-results-dark.png`、`results-narrow-en.png`。本轮验证为隔离快照和协议夹具，不代表实时桌面操作、真实音频输出、动效帧率、完整工作区或三平台验收。

回滚可移除主窗口搜索浮层、F4 隧道处理及搜索 VM，将 `OpenSearch` 恢复为原 `search` 路由；查询服务、曲库、扫描和音频无需回滚。
