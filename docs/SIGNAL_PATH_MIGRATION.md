`PlaybackSessionCoordinator` 仍是唯一播放事实 owner。`PlaybackLevelMeter` 接收现有 `audio.levelMeter`，只聚合最多八声道的峰值/RMS，单个待处理帧合并，按 transport epoch 和 operationId 拒绝旧通知。Meter 为独立订阅类别，不唤醒播放栏的普通状态订阅。电平没有 PCM、频谱或历史数组驻留。

`SignalPathViewModel` 只在弹窗打开时持有一份快照、一个分类订阅和一个 100ms 取消式更新任务；UI 最多一项待投递更新。关闭取消任务、解除语言事件并释放订阅，迟到更新检查 disposed。暂停、换会话或超过一秒没有新帧时显示未知电平。源文件采样率来自当前曲目资料或原生源信息，不能把播放时钟采样率充作源格式。设备硬件率只读取确认后的输出；未收到设备声明和上限时显示未知，不用配置推断 bit-perfect。
