# UI 深化第二轮

日期：2026-10-02。延续 Semi 与现有页面结构，本轮只调整展示、命中反馈与编辑框焦点。

## 已接入

- 专辑详情：封面最大 264 DIP，标题根据实际正文可用宽度和内容密度计算字号，保留完整标题提示；窄窗口的评分 / 资料改用换行面板，评分命中区域扩大。返回和艺术家入口使用轻链接，列表补充键盘焦点时的播放提示。
- 艺术家详情：首屏介绍区域缩至 280–420 DIP，正文标题及姓名装饰收敛，曲目在首屏更早出现；封面操作使用 ECHO 的轻模板，避免 Semi 状态底色与白色文字冲突。
- 公共控件：详情 / 艺术家 / 电台 / 历史 / 队列标签使用一致的透明底与既有选中标记；评分、工具及音量控件保留轻量命中反馈，播放控制弹层减小圆角。
- 电台：沿实际单独页面入口统一 32 DIP / 紧凑 24 DIP 内边距，保留页面自身的边距 owner；展示与网络提示、编辑、导入 / 导出及播放能力保持原接口。
- 歌词：独立顶栏样式跟随已有 ChromeTheme 明暗判断；播放控件禁用 / 焦点状态采用局部轻模板；队列关闭遮罩保留自身半透明底色，避免被普通按钮的 hover 样式覆盖。
- 网盘编辑：地址输入在可见性 / 模板更新后聚焦；主题切换导致地址失焦时有窗口内恢复。最多一个待执行 Dispatcher 工作项，无定时器、I/O 或全局订阅；控件关闭 / 离树后不聚焦，主动选择其他文本框时不抢焦点。

新样式均由现有 App 或视图装配。新焦点逻辑由连接编辑控件拥有；没有新增数据库写入、音频、曲库驻留或后台工作器。保留其他并行改动，不修改文件夹接口及实现。
