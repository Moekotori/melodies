# 曲目排序与筛选对齐

参考本地 Electron ECHO 的 SongsSortOptions、songSortMenuConfig、songSortSelection、SongsFilterPanel 和对应样式。

- Control：排序菜单按浏览／聆听／音频／曲库分组，方向按钮独立切换，多选按选择顺序显示优先级。取消最后一项回到默认排序；默认与随机为单独排序；艺术家＋专辑与单独艺术家／专辑互斥。最多保留契约中 21 种不同排序字段，查询及视图仍按页加载。
- 契约与持久化：保留原枚举值和前三项设置的兼容性，新增完整排序序列及多选开关保存。随机种子属于当前分页会话，进入游标身份，翻页不重新随机。
- 曲库适配：排序、重复条件及组合筛选在现有曲库查询 owner 执行，桌面不加载整库再排序。专辑倒序仍按正向碟号／曲序排列，未知年份、BPM 和音频规格放在已知数据之后。
- 元数据：扫描器已有的码率与 BPM 现在进入曲库；WAV 使用数据率，FLAC 使用音频帧字节数与采样时长计算平均码率，原生扫描器返回其他格式的技术数据，虚拟曲目复用物理音源码率并保留自身 BPM。Schema 22 增加字段及重复身份／码率／BPM 查询索引。旧数据在正常重新扫描后取得新字段，不在打开筛选弹层时扫描。
- 筛选：基础条件对齐为全部／重复歌曲；文件夹、年份和流派支持搜索当前有界选项，流派最多加载 256 项。搜索不清除现有筛选，关闭下拉恢复所选标签。已有收藏、无损、来源、位深、自定义年份／流派保留在可见的更多筛选入口中。
- 重复歌曲使用现有文件夹逻辑相同的标准化标题、艺术家与 0.5 秒时长容差；Electron 的完整严格重复分组服务尚未迁入，两者不能视为完全相同的重复判定。
- 歌词／逐字歌词、人声筛选依赖的完整事实索引与检测任务尚未迁入，因此本次不显示无数据支持的选项。
- 样式：排序宽度 252、筛选宽度 366、弹层圆角 14，按 ECHO 的 12px 排序文字、10px 分组和 32px 行高调整。菜单样式单独维护，避免工具栏激活样式污染弹层内容。

验证：Desktop 构建；独立临时数据库中的排序、重复条件交集、未知值顺序、随机游标和翻页完整性；Avalonia 无头渲染中的选项搜索、四级优先级、互斥、取消、设置恢复及浅／深色截图。该验证不表示真实桌面窗口、真实设备播放或完整桥核迁移已验收。
