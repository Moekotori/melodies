# 全局 UI 视觉优化

更新：2026-10-02。以现有 Semi 控件主题为基础，保持曲库、扫描、播放会话和原生窗口职责。

## 展示与调用

- `EchoLayout.axaml` 提供页面标题与 32 DIP 页面边距，以及内容链接、轻按钮、菜单和弹层样式；App 装配，现有主窗口及页面实际调用。
- 默认正文采用 Segoe UI / Microsoft YaHei UI，保留用户已保存的字体选择。侧栏采用弱分区底色、较轻字号及图标；标题统一应用于专辑、艺术家、流派、网盘、电台、歌单、队列、搜索和历史等页面。
- 首页依照已取得的有界快照区分曲库和欢迎状态。新 `HomeWelcomeView` 只有两个实际导航入口与静态唱片几何，不读取文件、不启动任务、无动画驱动或图像缓存；窄视口隐藏装饰。已有音乐时使用 220 / 144 DIP 封面、紧凑统计与现有分页内容；首页歌词采用纯文本链接。
- 曲目列表使用 72 DIP 行高、统一内边距、轻选择反馈，保留虚拟化、稳定选择、播放与筛选接口。
- 播放栏缩小封面，播放键采用明确的圆形强调色与同一会话状态绑定。无歌曲时展示空闲说明和静态进度轨道；有歌曲时保留原有有界装饰波形，不把它当作音频测量。缩放与命中区域仍由既有窗口及控件负责。
- 设置使用分隔线和 Semi 开关，移除未再调用的自定义开关模板；收紧导航及内容双重留白，解决重复标题和外观模式选择触发初始自动滚动的问题。保留绑定、快捷键、无障碍名称与控件语言。
- 队列抽屉减小圆角，公共弹层、提示及页面控件使用现有语义资源。

没有新增数据库或后台 owner。新增欢迎视图无订阅、缓存、CTS 或计时器，随页面释放；高频进度仍由原控件局部绘制。未增加逐帧全树更新、磁盘读取或曲库驻留。
