# 右侧播放队列窗口

日期：2026-10-02。按用户提供的右侧浮窗参考，接到已有播放会话与底栏队列入口。

`QueueOverlay` 覆盖主页面和歌词舞台，沿用统一有限动效和 UI 缩放。窗口自适应宽度，支持外部点击、Esc、关闭按钮、Tab 循环和关闭后的焦点恢复；导航关闭，快速反向只保留最新状态。退场结束卸载 `QueueDrawer`，可见封面租约随控件脱离释放。

`QueueDrawer` 显示实际播放状态、当前歌曲/来源、待播数量、播放顺序菜单、清空、文件添加、完整队列、搜索和撤销。键盘图标打开现有快捷键设置。普通衔接只显示现有能力；推荐电台、无缝/智能衔接没有生成无效入口。

`QueueDrawerPresentation` 只投影当前队列窗口：复用 `QueueViewModel.Rows` 的 DTO 引用，最多 1000 条；当前项和顺序中已播项不重复进入待播列表，搜索不改变总待播计数。没有新增音频/数据库 owner，所有编辑使用原有有界命令通道。位置事件不重建列表。单行移除、双击/Enter 播放、拖动、多选与键盘编辑仍使用原队列命令。封面复用现有缓存与取消/租约规则，UI 不执行文件 I/O。

验证入口：`tools/Echo.Preview --queue-window misc/queue-window/previews`。示例曲目和封面是展示夹具，音频是协议模拟；截图来自实际 Avalonia 控件。当前工作区存在并行模块编译中间状态，固定验证快照保存在 `misc/queue-window/snapshot`。只在该快照修补与队列无关的编译阻塞：播放器 DispatcherTimer 参数顺序、电台 Pen 类型、曲目页重复属性、文件夹未完成样式/旋转绑定、主题分组未完成展开绑定；快照禁用原生产物复制，并仅编译队列短测入口。原始模块不作这些修补。

最终短检查通过：真实鼠标单行移除/撤销、搜索不影响待播总数、当前与已播项分离、清空保留当前会话、30 次位置事件保持行引用、Esc/外部点击/焦点恢复、关闭控件卸载、英文紧凑窗口及歌词舞台。1000 项队列显示 999 条待播 DTO，实际只创建 7 个行控件。最终短检查约 4.7 秒；所有构建、失败与重跑累计约 97 秒，单条均低于 60 秒。最终快照构建 0 错误，有 5 个非队列 XAML runtime loader 构造器警告。原工作区整体构建的并行阻塞仍单列，不能以快照成功宣称整体全绿。

截图：`misc/queue-window/previews/queue-window-light.png`、`queue-window-dark.png`、`queue-window-empty.png`、`queue-window-compact-en.png` 与 `queue-window-lyrics.png`。这轮不重跑已有真实 Native Host smoke；实机输入/音频、三平台和长期性能未验收。回滚恢复原队列覆盖入口与控件；会话、数据库 schema 与生产曲库不变。
