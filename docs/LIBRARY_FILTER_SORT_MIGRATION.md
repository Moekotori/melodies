# 专辑筛选与排序迁移

日期：2026-10-02。入口：专辑墙右上角的筛选、当前排序及升降序按钮。

## 方向与选择控件重做（2026-10-02）

方向使用 12×14 的双向小三角，当前方向实色、反向低透明度；选中字段用主题强调色。`SortDirectionIcon` 只缓存两份几何，不读取图片、不创建每帧几何或定时器。删除旧长箭头的旋转状态，仍调用原排序命令。

筛选改为统一的轻底圆角输入与紧凑下拉选项；复选框为 16×16、4 像素圆角，选中紫底白勾，保留原 CheckBox 的输入/可访问性语义。多选开关改为白色滑块与强调色开启状态。主题色仍从窗口资源读取，作用范围限于曲库弹层。

当前 Desktop 与依赖 Release 构建通过（5 个其他窗口的既有 XAML 警告）；原生鼠标输入验证下拉项实际选择、父筛选面板保持打开、勾选/取消、排序方向和多选优先级。截图与日志在 `misc/library-control-redesign/`，包含展开下拉、开/关复选框、明暗及实际控件局部图。构建、早期依赖失败和重跑累计少于 40 秒，没有全量测试、性能重测或打包；运行中的用户窗口及三平台另行验收。

## 弹层视觉收口（2026-10-02）

按用户新参考图收紧专辑/曲目弹层：排序内容宽 252、专辑内容高度上限 410，外框约 270 宽；白色主题表面、细分隔线、14 号半粗选项、淡紫选中行、灰色行内单箭头与右侧勾选。方向点击保持菜单打开，一次提交完整排序状态；按钮显示 A–Z/最新/播放次数最多等当前语义。曲目已有多级排序改为紧凑开关，保留选择顺序与最多三字段的查询能力。筛选使用窄幅对齐行，保留目录、条件、重置和列数，移除重复重置及外置方向按钮。

共享 `LibraryPopupStyles` 只负责弹层主题、控件密度与开关绘制；语义颜色随主题更新。沿用原索引/分页/取消，不新增数据库读取、动效循环或常驻任务。定向 Release 构建及真实 Avalonia 输入检查通过（其他窗口仍有 5 个原有 XAML 警告）；检查方向切换、多选优先级、嵌套筛选、错误恢复、主题/语言和离页释放。构建、失败重跑及交互累计约 66 秒，未跑全量或打包。

完整实渲染与 96 DPI 原控件局部截图位于 `misc/library-popover-polish/preview-final/`。预览只编译本轮入口，Desktop 使用当前完整源码；早期并行任务的任务栏依赖、历史图表、侧栏错误日志保留，没有修改这些模块来绕过检查。

## 交付范围

只读对照旧工作区 `src/renderer/pages/albums/AlbumsSortControl.tsx` 与 `AlbumsFilterPanel.tsx`。新界面按浏览、聆听、音频、曲库分组，提供默认、标题、艺术家、发行年份、最近播放、播放次数、随机、时长、最近加入、歌曲数量、入库时间、文件修改时间。适用字段通过行内箭头切换升降序；默认、最近加入、最近播放、随机保持各自方向。保存排序和筛选偏好，沿用艺术家/流派专辑入口。

筛选复用曲目、专辑和艺术家的同一输入模型：本地文件/CUE/osu!、格式、采样率、位深、年份、流派、目录及其子目录、收藏、无损。支持目录选择、手输路径、活动数量、重置和可滚动面板。组合筛选必须由同一成员曲目同时满足；专辑收藏直接筛专辑个人状态。非法年份显示提示并清除旧结果；排序、筛选或搜索切换立即取消旧请求，异步迟到结果不能覆盖当前页面。

当前本地目录入口不提供网盘查询；旧版网盘提供者尚未迁入。入库时间使用持久化的 `tracks.created_at`，不伪装为文件系统创建时间。最近加入沿用现有专辑 `added` 聚合字段。默认保持标题顺序；没有生成语言相关的拼音排序键。

## 实现、所有权与性能

- Contracts：追加枚举值，保留既有偏好值；随机视图追加有界 16 位十六进制 pivot。
- Infrastructure：v12 新增专辑浏览聚合及索引；v15 对齐并行迁入的 v14 历史完成/资格与 epoch 规则。迁移和触发器都由现有唯一 writer 执行，不增加写连接，不接触旧 ECHO 生产库。
- 排序直接使用索引和 SQLite LIMIT/OFFSET；数值排序的稳定尾键改为与索引匹配的专辑 group ID，标题/艺术家沿用有效元数据索引。最近播放和播放次数不在翻页时实时聚合历史。
- 播放次数统计当前 epoch 内已结束且达到历史资格的事件；最近播放包含当前播放记录。进度 upsert 不重复计数或增加排序 revision。结束、资格变化、移组、missing、恢复与历史清空更新派生事实。
- 随机序列使用持久化随机键索引和视图 pivot；每次最多两段读取，刷新/重新选择随机改变起点，翻页稳定、不重复。它是随机序列的循环移位，不是每次刷新独立重洗整库；不执行 `ORDER BY random()`。
- 普通文件目录使用规范化 `path_key` 区间，虚拟来源检查真实 AudioPath；查询没有 UI 文件 I/O。
- 每页最多 200、墙面最多三页/600 DTO；计数和 pivot 缓存各最多 16 项，受 revision 与完整查询条件约束。使用既有独立 SQLite reader、读中断和排队取消；120 ms 输入防抖，离页解除订阅并释放页面/图片。
- Desktop：`AlbumSortControl` 负责分组菜单与按钮，`AlbumsViewModel.Sorting` 负责局部选项/语言/随机状态；共用筛选控件不持有曲库数据。

## 限时验证

隔离夹具与输出均在 `misc/browse-validation/`。只启动和停止本轮进程，没有全量测试、长期 soak、原生音频改动或完整打包。

1. 小型真实 SQLite：12 种排序的双方向完整分页、随机跨尾页/越界/重复、组合筛选交集、收藏、历史幂等、未结束→完成、移组、清空的统计与 revision、取消全部通过。
2. 复用固定生成快照，实际 50,000 曲目 / 10,001 专辑；v3 等历史版本升级至当前 schema 首次约 9.36 秒，包含其他模块已有迁移，不能算作本模块独立升级耗时。已升级快照打开约 35 ms。
3. 最终 Release 查询短测：24 次 offset=9600、limit=200 深页样本中位数 8.9 ms、最大 52.9 ms；6 次格式/采样率/位深/目录组合首屏样本中位数 43.1 ms、最大 91.3 ms。包括计数/pivot 冷缓存，机器仍有并行开发负载。早一轮深页中位数 3.8 ms、最大 13.0 ms，不能只挑该轮作为稳定保证。
4. 最终实际 Avalonia Headless/Skia 检查菜单输入、方向、随机页面驻留上限、下拉框展开保持父面板、非法年份恢复、中英语言与离页释放；明暗截图见 `preview-final/`。
5. 最后 Desktop 全部源码 Release 定向构建通过（使用已构建依赖，7 个其他功能的 XAML 警告）；Preview 只编译本轮实际预览入口通过，未隐藏 Desktop 诊断。早期因并行历史、播放栏、歌词和拖放测试源未完成产生的失败日志保留；临时隔离规则最终已移除对 Desktop 的排除和警告抑制。构建、失败重跑与两轮定向验证累计约 95 秒。

这些是生成数据的少量 SQL 样本，不包含封面读取、完整 UI 输入到呈现耗时、真实 HDD、长期稳定性、三平台或旧版全功能对照。当前工作区存在并行改动；普通整树构建的阻断、隔离预览及最后源码状态按 `misc/browse-validation/*.log` 记录，不把隔离成功当作整个工作区全绿。

回滚 UI 可恢复原专辑排序入口；数据库新增字段/索引是独立新格式库的一部分，旧版本 schema reader 不应打开已升级文件。保留升级前新格式库备份；不改旧项目或生产库。
