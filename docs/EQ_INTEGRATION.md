# 参数 EQ 接入与增强

2026-10-20。入口为音效处理 → 参数 EQ。本轮基于现有 31 段原生 EQ、六类滤波器、声道作用域、四段动态处理、A/B、撤销、预设管理和独立耳机链补齐控制体验，不重复建立播放器。

## 职责

- Control：简洁／专业编辑、快捷调音、静态响应及余量估算。快捷调音形成普通 EQ 参数；不创建另一套处理链或持续分析任务。
- Core：沿用现有 `IPlaybackSession.DspAsync` 串行命令和恢复记录，以及 `IDspResourceClient` 的预设资源管理。生产桌面经 Core 客户端发送请求。
- Audio.Host：沿用原生 EQ 的平滑、滤波、动态检测和实际输出。试听反馈只在宿主回执后显示确认；失败保留草稿和错误。

## 本轮变化

- 简洁模式增加 ECHO 的低频、人声、空气感、温暖及平直曲线，按对数频率插值并自动设置前级；切换到专业模式继续编辑同一组参数。
- 静态响应使用预计算系数与按原生槽位顺序相乘的复数矩阵。左右声道分别绘制；纯 M/S 使用中置／侧向视图；混合处理显示左右直达及交叉路径。通带、陷波和零基础增益的动态频段保持可见。
- 自动前级根据整体矩阵的最大奇异值及每行幅度和估算提升，搜索 DC、接近 Nyquist、对数网格和高 Q 中心邻域；活动动态向上频段每段保守保留 6 dB。前级维持原生 −12…+6 dB 范围，超出时明确提示降低增益或增加处理链余量。
- 余量是频率响应估算，不保证实际采样峰值、相位瞬态或采样间峰值不会削波，也不包含其他 DSP。没有正在播放的格式时明确标记采样率为估算。
- 曲线几何最多缓存四条声道路由和八条单段曲线，悬停复用；参数变更合并更新余量读数。试听共用一个 worker，约每 90 ms 合并最新参数且最多一个请求在途；离页取消等待，迟到回复不覆盖新状态。
- 窄窗口前级操作自动换行，保持应用／还原等操作可达。

参考只读 `E:\ECHOSteam` 的 `eqChannelResponse.ts`、`eqHeadroom.ts` 和 `eqSimpleToneVoicings.ts`，没有改动参考检出。交互参考 [Roon 参数 EQ](https://help.roonlabs.com/portal/en/kb/articles/dsp-engine-parametric-equalizer)与 [Headroom Management](https://help.roonlabs.com/portal/en/kb/articles/dsp-engine-headroom-management)的独立滤波和增益余量组织。

## 验证

### 界面精修

EQ 单独维护 `EqEditorStyles.axaml`，浅色使用轻盈画布，深色使用冷灰渐变，统一曲线、细网格、选中节点、参数输入、频段块、分段按钮和前级滑杆。主题切换立即重绘曲线；滑杆保留键盘调节、拖动与可见焦点，不新增动画或轮询。修改只涉及 Control 展示，不改变 DSP 契约和原生滤波。

本轮隔离构建 0 警告／0 错误；真实控件检查包括滑杆键盘／鼠标输入及原生回读、明暗主题、简洁／专业、高级参数／预设展开和多种窗口尺寸。精修截图位于 `artifacts/eq-polish-preview/`。沿用下述隔离验证边界，未据此声明整个并行工作区构建完成。

聚焦入口：`tools/Echo.DspPreview <截图目录> <原生宿主路径> eq-only`，独立测试资源目录和独立原生宿主，不触碰生产 EQ 预设或用户曲库。

- 解析数值检查：独立左右声道不错误叠加增益、高 Q 中心、M/S 隔离、混合顺序与交叉路径、动态余量、陷波可见性。
- 实际宿主回读：快捷调音、500 次快速修改后的最终值、试听回执、超过四段动态处理时整笔拒绝、还原、A/B 和 Core 资源服务保存预设。
- Avalonia 实际渲染：加载完整中文资源，简洁／专业、明暗主题、1440×960、920×780、760×900 和 1140×700。截图在忽略目录 `artifacts/eq-integration-preview/`。
- 原生 `echo-eq-precision-tests` 和 `echo-eq-editing-tests` 通过，覆盖双精度级联、32 声道、作用域隔离、旁路、强度、监听及试听释放。
- 曲线计算对比：Windows x64、.NET 10 Release，同一组 31 段、421 个频率点，预热后 100 次均值；仓库原实现约 3.035 ms／13,501 B，新实现约 0.902 ms／1,900 B，响应校验和一致。仅统计计算与线程分配，不包含绘制、进程树驻留或音频处理；基线及日志保存在忽略目录 `misc/eq-perf/` 和 `misc/eq-perf.log`。

Desktop 曾使用现有依赖完成定向构建。收尾时完整工作区被并行艺术家模块的编译／XAML 绑定修改阻塞；本次 EQ 源码另在 `misc/eq-current/` 隔离编译并运行相同生产控件和宿主检查。验证副本替换命名空间以避免和已构建壳程序集冲突；耳机页面采用之前可编译的快照，隔离其正在进行的并行契约改动。不能当成最新全工作区构建通过。

真实设备听感、持续播放、跨机器输出和 Native AOT 发布未在本轮验证；不宣称音质优于 ECHO／Roon，也不宣称 Electron EQ 的实时频谱、实测响度匹配及盲听周边全部迁移。
