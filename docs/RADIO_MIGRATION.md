# 电台页面迁移

日期：2026-10-02。入口：侧栏「电台」。视觉依据为用户提供的电台截图，旧版地址与 NET 标识算法只读取自 `D:\ECHO`。

已复刻标题/说明、导入和添加按钮、状态与收听入口、NET 大数字和刻度、全部/收藏标签、搜索、紧凑表格与底部管理入口。主题与图标复用现有原生资源，标题栏、侧栏和播放器仍使用现有模块。

功能包含新增/编辑、URL 校验、收藏、删除/全部删除确认、名称/简介/类型搜索、M3U/M3U8 导入和 M3U 导出。默认仅加入 ECHO Radio；截图中的 Zeno 是预览夹具，不写入用户配置。删除默认电台后空列表按原样保存，不自动重新加入。

收听使用既有 `PlaybackSessionCoordinator` 的直接 HTTP source 和串行命令通道，开始收听沿用单曲播放的替换队列语义；停止经同一会话 owner 执行。连接、播放和失败来自真实快照；未收到原生确认时保持「连接中」。进入电台界面打开原生简洁收听舞台。没有另起音频进程、解码器或网络轮询。

职责及资源：

- `Echo.Contracts/Radio` 定义有界电台 DTO 与存储端口。
- `Echo.Application/Radio` 的 `RadioCatalog` 是每个 shell 唯一电台资料 owner；串行确认写入后公布，容量 200，地址 2048 字符，简介 512 字符。`RadioPlaylist` 负责纯 M3U 解析与导出。
- `JsonRadioStationStore` 是装配时注入的存储实现，在后台异步读取/写入独立 `ECHO Avalonia/radio-stations.json`；读写均限制 1 MiB，临时文件原子替换。不接触旧生产库。
- `Features/Radio` 管当前筛选/编辑/显示状态，最多 200 行；刻度仅按需绘制，没有定时器。页面脱离取消未完成操作并解除 catalog/player 订阅；离页继续播放由原播放会话持有。
- 取消覆盖资料排队/文件操作及既有播放命令准入；不能据此声称已强行终止进入原生执行的播放请求。

验证：独立输出目录曾完成桌面及电台预览编译；共享输出文件占用、旧预览工具的 `IStorageFile` 实现和并行 `LibraryMultiSwitch` 缺少 `PART_MovingKnobs` 分别造成后续阻塞。最终对当前源码的固定副本验证，临时补齐该开关模板并复制已有运行时 EXE；原工作区的非电台源码未修补。

原生 Headless/Skia 短测通过标签真实鼠标输入、搜索空态、编辑与无效 URL、收藏/修改读回、M3U 往返、HTTP 播放命令、原生状态确认前后的展示、收听舞台、停止、离页释放及删除默认后重开。音频与网络是协议夹具。生成明暗、编辑、空态、舞台和紧凑窗口 PNG，位于 `misc/radio-validation/screenshots/`。

构建/失败重跑/短测累计约 107 秒，每条均设上限，只停止自己启动的进程树。视觉检查发现紧凑窗口过多堆叠会挤掉列表，已改为按各工具实际宽度换行，并在短窗口收起服务说明/主推荐区；这项最后的局部布局修正未再次编译或截图，避免超出整轮预算。现有紧凑 PNG 是修正前的诊断图，不作为最终验收图。

上述记录为页面首轮验证；紧凑布局与真实网络播放已在下面的功能实装轮补验。

## 功能实装与真实播放（2026-10-02）

- `IRadioStreamResolver` / `HttpRadioStreamResolver` 在播放前执行真正的 HTTP 头探测，解析普通 M3U、PLS、相对地址与重定向，HLS 保留 manifest 交给原生宿主。读取 ICY 名称、简介、类型和声明码率，音频数据由既有 Native Audio Host 解码。
- 探测并发上限 2，单次含排队最多 6 秒，重定向最多 5 次，列表最多 4 层/256 KiB/4096 行。HTTP/HTTPS 地址不接受嵌入凭据；直接音频只读响应头，关闭连接，不在托管进程缓存或转发 PCM。
- `RadioPlaybackService` 每个 shell 一份，只拥有当前解析请求和 generation。切换/取消会撤销旧探测；探测期间的新歌曲、seek 或暂停命令优先，迟到的结果不能覆盖新播放。播放与停止仍经原会话唯一命令 owner。
- 原始电台 ID/URL 保存在队列 origin/metadata；播放使用解析出的音频 URL，页面往返与播放器入口仍能找到原电台。删除正在播放的资料不会使停止入口消失。
- 连接时按钮允许再次点击取消，探测失败和直播结束提供重新连接；暂停的直播继续播放时重新打开源，从直播位置开始。离页取消未完成探测，已经确认的播放由会话继续持有；退出释放服务与 HTTP client。
- 主播放器显示直播状态及已收听时间，隐藏文件波形进度；歌词栏和迷你窗口禁用直播 seek，播放核心也拒绝直播 seek 而不把会话变为故障。系统媒体映射的直播时长为零，禁用 seek。有限文件播放的原路径保留。
- 点击主播放器封面或歌词入口会打开正在收听的电台舞台；普通歌曲继续进入歌词页。现有收藏、编辑、独立资料保存与 M3U 导入导出继续使用原有 catalog/store。

本轮结果：核心/基础设施定向编译 0 警告、0 错误；地址解析和会话短测通过。真实访问默认 `https://echonext.moe/radio/stream` 后，实际 Native Audio Host 进入 Playing，设备播放时钟推进到 0.070 秒，输出报告 48000 Hz / 2 ch；音量设为 0，是静音设备渲染证明，未进行物理听感验收。另用本机 HTTP/M3U 音频夹具验证真实解码、暂停后新 operation 重连、停止确认。

原生 UI 短测使用协议夹具，通过真实鼠标的连接取消、失败/重试入口、直播 seek 禁用、播放器封面导航、资料/收藏读回、M3U、离页释放与修正后的窄窗口列表。明暗/编辑/空态/舞台/窄窗截图已更新到 `misc/radio-function/screenshots/`，与真实网络验证日志分开。

共享工作区第一次桌面构建超时，第二次被并行新增的 `RemoteView.axaml` 中非 AvaloniaProperty 的 `ColumnDefinitions` 样式 setter 阻塞。验证固定复制 Desktop 源码，仅在临时副本去掉这四个无关 setter；依赖仍使用当前工作区已编译的核心/基础设施。电台、播放栏和播放器逻辑未做测试替代。副本编译通过，保留 6 个既有/无关 runtime-loader 构造警告，预览工具编译 0 警告、0 错误。原工作区的网盘源码未修补。

本轮构建、失败重跑、真实 Native/网络和原生 UI 验证累计约 87 秒；日志与自动累计预算在 `misc/radio-function/`，只终止自己启动的超时构建树。
