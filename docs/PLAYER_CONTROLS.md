# 右下角音量与速度控制

入口：主播放栏右下角的调节图标；歌词底栏沿用同一个 `PlayerVolumePanel`。

- 音量 0–100%，滑条/方向键、±5%、静音并恢复原音量；锁定仅阻止本面板的音量操作。
- 速度 0.50–2.00 倍，滑条/方向键、±0.05、一键恢复 1 倍。
- 输出按钮打开既有音频设置抽屉；迷你按钮切换已装配的迷你播放器。
- 文字与颜色使用现有中英资源和语义主题，弹层跟随主题与语言。

## 所有权与恢复

`PlaybackSessionCoordinator` 仍是唯一播放 owner。速度经现有 `playbackRate.configure` 通道提交，读取原生回执中的 rate/mode 后才发布 `PlaybackSnapshot.PlaybackRate`；音频设置和快捷键调用同一通道，因此弹层会收到速度更新。恢复状态保存原生确认参数，启动/设备重建/显式恢复时重放并重新确认；恢复 checkpoint 可显示前次保存的速度，不自动播放。

滑条只持有本次拖动的局部预览，松开或键盘调整结束时提交一次。关闭、失焦、切换上下文和脱离视觉树取消尚未提交的预览；已提交的命令归现有有界串行通道所有。失败保持原确认值并显示播放器错误。面板无文件/数据库 I/O，无整库、定时器或新增后台 owner；仅增加两个小控件树与既有有界图标资源，脱离时图标和预览释放。
