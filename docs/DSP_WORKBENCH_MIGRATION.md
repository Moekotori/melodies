# 音效处理工作台第一版

2026-10-02。入口为主侧栏的音效处理，沿用旧版 `DspPage.tsx` / `DspSidebar.tsx` 的独立模块侧栏、分组、模块状态摘要和编辑区，默认进入参数均衡器。旧 `D:\ECHO` 仅作为只读来源。

## 当前能力

- 参数均衡器：原生 31 段读取、内置预设草稿、频率/增益/Q/六种滤波器、频段启停、前级/强度/倾斜、拖动曲线节点、平直和估算自动前级。
- 增益余量、安全限幅、ReplayGain、声道平衡/增益/延时、压缩器、交叉馈送、立体声场及声道矩阵：现有原生协议读取与确认应用。ReplayGain 的逐曲标签注入仍未迁移，不宣称完整响度归一化。
- DSP 机架：实际原生顺序与固定后置阶段只读展示；排序尚未迁移。
- 聆听方案、SRC、SDM、耳机与房间校正：保留旧版导航位置，明确显示待迁移与现有音频设置入口；尚无相应完整编辑器。
- 调整保留为本页草稿，点击应用才提交；失败保留草稿及原确认状态，支持刷新/还原和最多 16 次已确认编辑的撤销草稿。曲线是 RBJ 参数模型，包含原生对应的逐频段倾斜及棚式 Q 语义；不是音频测量。未知输出率不会用默认 48 kHz 冒充设备事实。

## 职责与资源

`Features/Dsp` 按目录、页面状态、参数/频段、预设、曲线计算、绘制及视图拆文件。`MainWindow` 只增加路由。所有读写仍经唯一的 `PlaybackSessionCoordinator.DspAsync` 有界串行 lane；不新增音频进程 owner、数据库连接或扫描逻辑。原生实现未修改。

页面只保存一个确认 JSON、一个编辑视图和最多 16 次撤销 JSON；EQ 最多 64 个频段，预设最多 128 个，机架最多 24 阶段。每次绘制最多 600 个曲线分段，没有定时器、PCM、频谱订阅或后台持续分析。Collection reset、重新绑定和离页均撤销频段绘制订阅。读取/应用有页面取消 token 和 generation，离页拒绝迟到 UI 结果；已发出的命令仍由播放 owner 收口。

确认请求沿用现有最多 128 项的 DSP 恢复状态及新应用 checkpoint；本页不自行保存或打开旧配置/生产库。草稿不跨页面保存。跨页记忆、完整中英文文案、预设编辑/导入导出、实时频谱/试听、整机架排序与高级编辑器待后续迁移。
