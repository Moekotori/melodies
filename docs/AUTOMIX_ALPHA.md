# 智能过渡 Alpha

设置 → 播放 → 播放偏好中的“智能过渡”启用后，默认使用 Alpha。
开关仍默认关闭，已有启用偏好保持有效，不需要另选版本。

Core 的 `Echo.Playback` 拥有分析、下一首选择与计划；Control 仅通过现有
`SetAutomixEnabledAsync` 契约控制开关。分析与播放不依赖窗口存活。
独立 Audio.Host 拥有解码、WSOLA、双 Deck、DSP、输出时钟与提交事实。
没有新增数据库访问、桌面分析器、PCM IPC 或 Bridge 队列。

## 对齐 ECHO

移植自本机只读 ECHO 参考代码（提交 `542e7c66c`，含 2026-10-19 更新）：

- Alpha AutoCue：最多 8 个结束点 × 4 个进入点 × 9 个长度候选，比较相对能量连续性、
  方向、相对电平、人声冲突和节拍漂移，包含 2／4／6／8 小节候选。
- 20 ms 频谱材料：RMS、低／中／高频与单极低频，按绝对采样边界取整，
  避免 11025 Hz 尾端漂移；进入材料按宿主 tempoRatio 读取。
- 六条自动路线：plain_blend、bass_swap、tail_ride、learned_eq、show_mode、beat_cut。
  路线评分、优先级和后备 Chooser 与 ECHO Alpha 对齐。
- 学习 EQ：相同 36 个输入特征、Float32 归一化、两层 14 单元网络、12 个控制值；
  完整权重编译为静态数值，不依赖反射、模型下载或额外运行时。
- 短切只占最后 30 ms，保留 fade end、commit 与下一首起点。
  任一频谱材料缺失／越界时保留既有节拍、小节、人声 handoff；固定边界淡化、
  echo throw 与不支持的输出仍沿用原路径，不编造分析证据。
- `automix.prepare` 必须回执相同 planId；含 Alpha DSP 的计划还必须回执
  `alphaDspAcknowledged`。旧宿主必须先确认取消再报告不可用。

与 ECHO 一样只迁入自动核心，不包含离线 Studio、WAV 导出或手动效果。
单曲循环、片段循环、变速、DSD 与 SDM 不启用智能过渡；本轮不扩大远程音源支持。
来不及分析时仍使用现有短交叉淡化。

## 资源与验证

复用每首最多头尾各 36 秒的现有解码结果，不增加解码进程或常驻工作器。
每窗口最多 1800 × 5 个 Float32（36,000 字节）；64 个分析缓存条目的频谱总上限
为 4,608,000 字节，短曲头尾共享同一数组。PCM 不进入分析缓存。
分析全局串行，取消等待者不启动解码；材料视图不复制数组，EQ 最多计算 800 hop。
下一首时长缓存限制为 64 条。关闭开关取消当前分析并等待已准备计划的原生取消回执。

聚焦验证入口：`tests/Echo.Automix.Smoke`。包含 ECHO 原始模型 oracle、真实频段与
分数采样率覆盖、六路线、材料不足保护、短切时钟与宿主接收／拒绝回执。
原生回归目标：`echo-automix-alpha-tests`、`echo-automix-alpha-update-tests`。
界面检查：`Echo.SettingsPreview --automix <输出目录>`，只用隔离的展示状态。
真实设备试听、发布版 Native AOT 和跨机器输出须单独验证。

2026-10-20 聚焦结果：Release C# 检查通过，覆盖原始模型 oracle、材料上限、
六路线、缺失频谱保护、30 ms 短切、EQ 控制传输及旧宿主取消回执。
两个原生 Alpha 目标构建并运行通过，固定 RenderBlend 状态为 9384 字节。
同步了旧测试的 8 KiB 过期断言与 Float32 参考路径：预算与已有更新测试统一为
10 KiB，精度参考改为与 RenderBlend 相同的 double 计算后单次转换，仍要求零误差。
没有扩大原生生产状态或修改 DSP 算法。

本机 Release、warm JIT、11025 Hz 单声道 36 秒窗口：新增频谱阶段分别测得
1.40／1.75 ms，分配 36,064 字节、结果驻留 36,000 字节。
这是新增阶段相对原有无频谱分析路径的成本，不是全播放器 CPU 或内存改善声明。
不包含已有 FFmpeg 解码、节拍与人声分析，不外推到后台 CPU 或真实音频设备。

界面预览未验收：桌面构建先遇到并行修改中的编译错误，后续输出复制又被正在运行的
Echo.Desktop 锁定；隔离预览构建时 Desktop ref 程序集也缺失。
没有停止现有应用，也没有修改其他会话的相关源码。完整桌面构建、实际界面与真机试听仍待验证。
