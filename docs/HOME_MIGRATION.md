# 主页功能迁移

更新：2026-10-02。对照旧工作区 `HomePage.tsx`、`components/home` 与 `home-editorial.css`；只读参考旧代码，所有曲库写入均在新格式数据库。

主页沿用旧版 280px 方形封面、26px 主图间距、四项曲库统计、四封面最近活动、88px 封面的双行横向推荐、本周热力图与艺术家侧栏，以及下方常听曲目、聆听画像、常听专辑。窄内容区域改为上下排列，使用现有主题和语言资源。

已接入当前歌曲、封面、格式与来源、继续/恢复播放、队列导航、刷新、36 项随机队列、最近入库/播放切换与翻页、推荐换一批、专辑/艺术家详情及返回、统计入口、常听歌曲播放、音质分布与听歌习惯。继续播放保持当前队列 occurrence；已经播放时不发暂停。随机列表读取最多 36 条，生成新的 occurrence 并保留虚拟音源范围。

职责与资源：

- `IHomeLibrary` 提供一个小型主页快照、随机曲目、当前歌曲专辑查询与幂等听歌记录写入。
- `HomeLibraryQueries`、`HomeListeningQueries` 在 SQLite 交互读取 owner 中完成聚合；返回最近入库/播放各 8、推荐 7、榜单 5 艺术家/6 曲目/4 专辑、格式最多 5、日期最多 84。UI 不持有事件列表和整库。
- `HomeViewModel` 持有当前快照及命令；同一时刻一个主页查询，重复刷新只合并一个待处理标记；离页取消查询和播放命令。
- `HomeView` 管布局、当前封面和详情导航；封面沿用应用 32 MiB 共享缓存，页面/卡片脱离时取消和释放租约。
- `DesktopListeningRecorder` 是窗口生命周期内单一播放订阅，离开主页仍记录；每 15 秒、播放状态变化和退出合并提交累计时长。同一 ID 使用最大累计值，不重复计次。暂停不累积，跳转不把跳过的音频时长加进统计，seek 不创建新播放记录。历史模块继续扩展同一事件表与写入 owner。

迁移范围：本地曲库的听歌事实从新应用开始记录，不自动写入或合并旧版生产历史。主页统计窗口为最近十二周。当前没有 Steam 登录/统计服务和远程曲库来源，所以旧版条件显示的 Steam 面板及远程来源切换不在普通本地主页中创建。当前歌词三行片段读取现有有界歌词服务，每秒最多四次文本更新，可点击打开歌词舞台；默认关闭的旧版信号可视化仍未迁入，不展示合成音频动画。

验证入口：`dotnet run --project tools/Echo.HomePreview -- misc/home-migration/preview`；通用预览工具也保留 `--home` 分支。专用入口避开其他并行预览用例的编译错误。每次运行创建独立新格式 SQLite，输入和截图使用原生 Avalonia Headless；音频端是协议夹具，不能作为实机输出设备验收。每条命令限 60 秒，整轮累计限 120 秒。

本轮通过记录：隔离桌面源码构建完成；专用预览工具 0 警告、0 错误。主页短测运行 3.71 秒，验证真实计数/结果上限、累计写入幂等、取消、实际鼠标翻页/随机队列、继续播放保持 occurrence、seek/恢复不重复计次、歌词片段、专辑/艺术家详情、主题/语言/窄窗口、导航释放。截图在 `misc/home-migration/preview/`。封面、曲目和歌词为明确的测试夹具。

末尾修正了活跃周数、紧凑时长与艺术家排名显示。此后当前整工作区构建被正在并行修改的 `SignalPathViewModel` DispatcherTimer 参数、`SongsViewModel` 属性访问阻断，末尾修正未重新生成截图；不能把此前通过的源码快照短测称为最新整工作区全绿。所有构建、失败重跑和短测累计约 102 秒，已停止追加验证；来源见 `misc/home-migration/*.log` 与 `validation-seconds.txt`。UI/实机/三平台验收仍分开。

回滚：撤销主页文件和主页装配入口，停用听歌记录订阅；保留新库的事件表。历史模块已共享该表时不得单独删除表或降低 schema 版本。旧工作区与生产库不受影响。
