# 旧版扫描实现迁移

本轮以旧 ECHO 实际实现为行为依据，直接复用能独立编译的模块；TypeScript 业务按同一规则转为 C#，不重新定义 CUE/osu 行为。

源版本：D:/ECHO，Git 3dbf28993cddf9f10ea355b88b0105abe85e5174。旧目录只读，生产数据库不参与开发验证。

## 实施计划

1. [进行中] 原样迁入 C++ library-scanner 和 C# ScanCueReader/ScanCueParser，记录来源与许可，保持新接口文件模块化。
2. [待完成] 迁入按文件夹的 CUE 展开/音频抑制、osu 元数据覆盖/共享音频去重与谱面属性缓存；各缓存与解析输入有上限。
3. [待完成] 让现有数据库保存物理音源、片段范围、谱面来源及依赖指纹；沿当前唯一 writer 迁移 schema，不回退专辑/艺术家模块。
4. [待完成] 通过现有 AudioSource.Range 接入 CUE 播放来源，保留旧版片段标识与新队列 occurrence。
5. [待完成] 定向验证源实现、虚拟曲目、增量、来源改变、缺失保护及 C++ 自动查找；构建/测试总预算 120 秒，单条最多 60 秒。

边界：直接复用 parser 不等于整个旧版功能已完成。旧 Core 的分析身份、playlist、封面写入和 schema 语义仍需逐能力迁移；旧 schema 不直接覆盖到新库。回滚以匹配的代码与数据库备份为单位，禁止删除用户曲库。
