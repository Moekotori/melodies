# 侧栏抽屉设置迁移

日期：2026-10-02。旧 ECHO 仅只读参考。

入口：设置 → 通用 → 窗口与启动 → 隐藏侧栏。鼠标进入窗口左边缘时展开，移出后关闭；边缘按钮支持点击，Ctrl+B 支持键盘打开/关闭。Esc、点击外部、选择导航（包括当前页面）和窗口隐藏都关闭抽屉。键盘打开后焦点进入导航，Tab 在抽屉内循环，Esc 恢复入口或原焦点。

## 职责与边界

- `ShellSidebar.cs`：窗口局部模式、打开状态、侧栏占位宽度。进入设置时隐藏侧栏优先，退出后恢复抽屉偏好。抽屉始终显示导航文字；退出抽屉模式恢复图标偏好。侧栏折叠按钮切回固定侧栏模式。
- `SidebarHost`：复用单个 Sidebar，负责边缘命中、鼠标/键盘输入、焦点、取消与有限过渡。打开时覆盖页面，不改变页面宽度；关闭时只有 22 DIP 边缘入口。不开新窗口，不创建 hover 定时器。隐藏导航立即退出命中与键盘导航，窗口隐藏停止局部动效，脱离视觉树解除窗口/VM/动效订阅并清理焦点引用。
- `MainWindow`：沿用布局 FLIP，只读取局部侧栏宽度。未修改曲库、扫描或音频路径。
- `WindowPreferencesBinding`：通过既有单工作器、容量 1 的设置 store 保存偏好。`DesktopPreferences` 增加默认 false 的 `SidebarAutoHideEnabled`，版本 1 的旧设置文件仍兼容。打开状态不持久化。新应用设置继续使用独立 ECHO Avalonia 目录，不读取旧版设置或生产数据库。

资源增量：一个边缘按钮、一个装饰容器、一个有限 MotionLane 和若干窗口局部字段。没有第二份导航列表、常驻后台工作或额外磁盘读取；设置文件仍受 8 KiB 上限约束。普通侧栏默认保持展开。恢复外观或侧栏默认值会关闭自动隐藏。

## 最小验证

定向入口：`dotnet tools/Echo.Preview/bin/Debug/net10.0/Echo.Preview.dll --sidebar misc/sidebar-drawer`。单条构建/运行设置 60 秒超时，只停止自身进程树；整轮累计低于 120 秒。

使用原生 Avalonia Headless + Skia，未装配播放、媒体控制或曲库服务。检查绑定开关、真实鼠标边缘/移出/外部点击、Ctrl+B/Esc、键盘焦点、导航关闭、设置优先级、图标模式恢复、快速反向、完整/减少/关闭动效、隐藏恢复、800 宽窗口与 150% 缩放时的抽屉尺寸、JSON 保存与旧文件兼容。原生浅深色和设置截图保存在 `misc/sidebar-drawer`。

本轮构建、失败修正与定向运行累计约 24 秒；最后 Debug 增量构建 0 警告、0 错误，定向检查通过。期间预览工具的并行设置 smoke 出现播放接口类型错误，已由对应并行工作修正，本轮未修改该文件。

Headless 操作和 PNG 不等于 Windows 实机输入、帧率或长期资源验收，macOS/Linux 尚未验收。窄窗口高缩放时，现有设置页列布局仍需另行适配；本轮只验证抽屉本身，不宣称设置页全部响应式布局已迁移。侧栏项目隐藏、排序、拖动和插件导航不属于这次抽屉设置迁移。

回滚：关闭“隐藏侧栏”即恢复固定侧栏；停止新应用可返回旧 ECHO。旧工作区保留，本轮不删除旧实现。
