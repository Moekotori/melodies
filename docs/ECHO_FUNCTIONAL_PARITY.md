## 本次补齐的歌单能力

参考 ECHO 的 `src/main/library/playlists/PlaylistFileImport.ts`、`PlaylistFileExport.ts`、`src/shared/library/playlistFileFormats.ts`，以及页面中的 `PlaylistRecoveryDialog` 和播放入口；这些参考文件未修改。

| 功能 | 交付结果 |
| --- | --- |
| 文件导入 | M3U、M3U8、PLS、JSON、CSV、XSPF、WPL、TXT；首页右上角“更多 → 导入歌单” |
| 文件导出 | 以上八种格式；歌单及喜欢歌曲详情的导出按钮。按当前搜索与排序导出整个结果，逐页读取，不限当前 200 行；JSON 保留名称与介绍 |
| 删除恢复 | “更多 → 恢复已删除歌单”；数据库分页读取归档记录，恢复歌曲顺序与重复 occurrence，关闭客户端或重启 Core 后仍可恢复 |
| 跨页播放 | 201–1000 项结果由 Core 分页准备并一次提交给现有播放 owner；播放、随机及追加覆盖整个匹配结果。选中行操作仍只作用于选中行 |
| 远程 Control | 使用相同类型化 RPC；歌单写入和文件转换明确加入远程 Control 白名单，Bridge 无写入能力；没有开放扫描、任意路径读取或音源 URI 执行能力 |

职责：`Modules/Echo.Playlists` 只转换文档；`Echo.Infrastructure/Library` 负责唯一 writer、索引匹配、事务和回执；`Echo.Core` 组合转换、分页和播放准备；`Echo.Desktop` 读取用户选择的文档、提交请求、展示当前页、原子保存导出文件。

数据与预算：导入只匹配已索引且未标为 missing 的曲目，跳过未入库/不可用条目并报告数量；不修改音乐文件、不主动访问文档中的网络地址。保留顺序与重复条目，不用路径集合去重。创建、全部条目与回执同事务；零匹配、提交前取消、无效文档均不留下空歌单或半份歌单。同操作 ID 重试核对指纹并返回原回执，现有回执保留 256 项。JSON/XML 使用明确解析，XML 禁止 DTD/外部实体；无反射序列化或新增生产依赖。

每份导入最多 512 KiB、10000 项，展开后路径合计最多 1048576 个字符；导出最多 4 MiB、10000 项，Core 同时最多两次文件转换。导出每页最多 200 项，带 revision 核对；文档写入有字节预算，不保留第二份整歌单元数据集合。Control 仅暂存一份有界文档，页面离开取消请求并释放恢复列表/文件流；本地导出先写同目录临时文件，完成后替换目标。ECHO 导入上限为 16 MiB，本增量受普通 Core 请求预算约束，尚未实现大文档分块上传。

播放继续遵守已有 1000 项和文本/序列化字节预算；超过 1000 项时明确展示“播放本页 / 随机播放本页 / 将本页加入队列”，不悄悄截断成前 200 项并声称完整播放。超长歌单连续供页仍需后续 Core 队列源实现。

## 验证入口与范围

`dotnet run --project tests/Echo.Playlists.Smoke -c Release`：独立生成库、真实 SQLite、真实 Core IPC 与两个客户端，音频回执为夹具。覆盖原子导入、指纹回执、缺失跳过、重复 occurrence、八格式跨页往返、搜索导出、跨页播放、随机保持全集、Bridge 拒绝写入、归档跨 owner 重开恢复、取消及容量拒绝；Avalonia 检查实际播放/恢复按钮和明暗/窄窗口渲染。

中途构建曾遇到并行窗口文件尚未完整及单次构建超时；这些不计为通过。最终结果及截图以本轮检查输出为准。真实文件选择器、物理音频输出、跨机器 Control、macOS/Linux 和 Native AOT 发布尚未由本轮聚焦检查证明。新接口是协议 v1 的显式增量能力，客户端与 Core 应一起更新，未知方法保持明确失败。

本轮另修复三条网络歌词英文文案缺少中文基准键的问题：`LanguageCatalog.ValidatePack` 原先会拒绝加载语言包并阻止界面启动；补入对应中文键，保留原有翻译和网络歌词实现。

最终聚焦结果：Core Release 及其依赖构建通过；Desktop Release 定向构建通过（使用已构建依赖，`BuildProjectReferences=false`，保留七条既有 Avalonia 资源警告）；Core/IPC 检查和 Avalonia 实际鼠标点击检查均通过。第二个客户端确认收到了跨页播放的新队列；恢复弹窗运行时切换语言及解除订阅均有相应实现。明暗、英文窄窗口及恢复后空状态截图位于本地 `misc/playlist-parity/45f107687773410c954342fbc083cf56/`。这不代表完整解决方案、真实输出设备、跨机器网络或 Native AOT 发布验证。
