# DSP 页面视觉检查

final result: passed

## 目标与证据

用户要求 echocsharp DSP 页面沿用 echosteam 的组织与交互，可以参考 Roon 做视觉改进。本轮为生产 Avalonia 页面的改造，不是网页原型，也不宣称逐像素复制 Roon。

- 参考：本地 echosteam 已提交的 DspSidebar/DspPage/dsp-chrome-polish，以及运行中的 echosteam DSP 页面；Roon 官方 MUSE Parametric Equalizer 的界面图与说明：<https://help.roonlabs.com/portal/en/kb/articles/dsp-engine-parametric-equalizer>。
- 本机前后比较：`misc/dsp-ui/comparison.png`，左侧改造前、右侧改造后，均为 1440×960 的实际 Avalonia 页面。前级 −4 dB，选中 1 kHz/+3 dB 频段。比较图只是证据拼接，不是产品资产。
- 实现截图：`misc/dsp-ui/after/` 保留首轮前后比较；`misc/dsp-all/screens/` 包含全部 19 个页面，以及真实 OPRA 搜索/原始/听感载入、light/dark、920×780、1140×700 与展开高级 EQ。
- 参考截图来自已打开的实际界面；后续机器锁屏，未继续操作用户桌面。实现检查通过独立 Avalonia Headless 窗口与本次启动的真实原生宿主完成，不打开生产曲库、不播放声音。

## 已发现并修正

- P1：展开高级导航时替换 ItemsSource 导致选中项被旧值覆盖，压缩器误回到 EQ。改为固定 19 个模块，仅切换条目可见性；检查高级模块选择和收起导航时保持当前模块。
- P2：920×780 时大曲线与原先三行参数挤占首屏。曲线随可用高度调整为 200–310 px，窄屏至多 210 px，参数改为三列布局，保留可滚动的高级区与固定应用栏；聚焦检查断言增益输入完整位于操作栏上方。
- P2：深色模式下安静按钮文字继承黑色。改为明确的 EchoText/EchoMuted 动态资源，最终深色截图中文字可读。
- P2：原曲线面积填充在不同画刷类型下可能变成不透明实色。改为固定低透明度填充、独立深色绘图区与白色主响应线，不再逐帧创建渐变画刷。

- P2：矮窗口内，原曲线控件 220 px 的最小高度超过绘图区，底部刻度被裁切。最小高度降为 160 px，保留边距；最终短窗口截图刻度完整，并增加曲线边界断言。

## 五项视觉检查

- 字体：沿用应用字体和 CJK fallback，ECHO 标记使用 Georgia/DejaVu Serif 回退；27 px 模块标题、25 px 参数、12–13 px 标签形成层级。Linux 字体实际回退未在本轮验证。
- 间距：左侧 236/188 px，输出固定在底部；曲线、频段、参数、前级增益顺序清晰。机架左链右参数，普通多参数模块宽屏双列、窄屏单列。高级 EQ 和预设管理默认收起。
- 色彩：保留主题动态资源、选中与启用语义；深色绘图区独立于页面主题，避免曲线与背景对比不足。没有新增装饰性渐变或大面积套卡片。
- 图像与图标：没有新插画/位图资产；沿用项目现有 GlyphIcon，EQ 是基于真实参数绘制的可交互图形，没有把截图作为页面替代品。
- 文案：沿用模块和参数名称，保留实际确认状态与草稿说明；没有添加不工作的伪功能。高级导航收起不改变当前处理模块。

## 验证范围与剩余项

C#/XAML 聚焦构建、全部 19 个真实 Avalonia 页面加载、模块导航、数值键盘输入、展开高级区、宽/窄/深色布局检查通过。真实 OPRA 搜索、原始/听感切换与载入后应用均连接实际宿主；鼠标按下/松开齿音监听按钮获得对应原生回执。验证资源目录隔离，不写生产库。Core 资源及原生参数检查见 docs/DSP_PARITY.md；没有长期播放、真实设备听感、Windows/Linux 或 AOT 发布验证。

P3：31 段横向列表滚动时可能显示半个边缘条目，选中项保持可见；这是现有横向列表的连续滚动行为，不影响参数编辑。整个桌面外壳及用户自定义主题组合未做全量视觉验收。

最终确认：生产页 C#/XAML 构建 0 错误（7 个既有 Avalonia 构造器资源警告）；独立预览工具构建 0 警告/错误，最终短时检查正常退出。高级收起保持当前模块、键盘编辑、固定操作栏、坐标标签边界均通过。原始分辨率下已核对参数行文字、暗色按钮及窄屏边界，无需另行放大裁剪。

## 全部 DSP 页面收尾

- P2：OPRA 同型号/同作者的结果无法区分目标，行内增加来源的目标说明。只分页展示 30 条，读取作者、详情与许可后再载入，原始/听感参数保留为两个独立对象。
- P2：载入参数后仍选中此前的禁用空频段。现在优先选择新预设内有效、有增益的频段；用户能立即检查实际作者参数。
- P2：耳机参数显示原生 Float32 转 JSON 的长尾噪声。编辑显示使用 G7；ViewModel、保存与导出的数值不量化，原始参数精度断言仍保留。
- P2：房间校正有重复导入按钮，简单模块受 MaxWidth 居中造成对齐不一致。统一左对齐并保留一个资源导入入口。
- P2：听音方案空库缺少说明，套用和删除仍可点击。补充空状态并按是否选中方案禁用操作；该页隐藏无意义的模块 A/B 操作栏。
- 页面均使用实际原生确认、草稿或待格式状态；没有模拟电平表、自动宣称 CUDA/DSD 激活或伪造 OPRA 搜索结果。压缩图明确为静态参数响应。

最终人工核对了全部页面的原生截图汇总及 OPRA 载入后的原始分辨率截图。确认标题、层级、暗色绘图区、参数、应用栏与来源文字可读；鼠标监听释放、键盘编辑及窄窗口边界断言通过。所有 19 个入口实际渲染、UI/宿主回执和 Core 资源检查均为短时聚焦检查。产品外壳、真实设备输出和所有自定义主题组合仍不在本轮验收内。

## 页面布局保真复查（2026-10-20）

用户指出多个模块与 ECHO 差异过大。已核对 source flat / spatial CSS 和各模块 JSX，修正先前通用等分表单、统一深色图框及错误分析图类型。新截图保存在 `artifacts/dsp-fidelity-preview/`，覆盖 19 个入口的浅色、深色及 760×900 布局。

重点检查 SRC 横向控制台、Headroom 大读数与侧栏、空间图表透明背景与参数摘要、去齿音检测带及多段分频图。没有调制器系数和动态历史的连接显示等待状态；目标 LUFS 和库分析入口禁用并解释接口未提供。前文关于所有图表均为深色及普通多参数页等分布局的描述仅适用于之前的版本。

最后检查还覆盖透明图表空白区域的鼠标命中、去齿音拖动后原生回读与多段图点选。房间页未载入 IR 时隐藏余量侧栏及增益，避免空资源状态显示 0 taps 等无效配置。当前 DSP 独立编译无警告、无错误；整桌面最新构建受并行艺术家页 `IsOverview` 绑定缺失影响。OPRA fixture 本轮缺失，未作为复测通过项。

深色复查另修正普通操作按钮的文字对比度：DSP 范围显式跟随 EchoText，主操作的独立样式继续生效。Headroom 建议与按住对比按钮在深色下保持可读。

## 空间页尺寸修正

交叉馈送原先固定 330px 图表，外层按内容高度排列，1440×960 窗口下底部留下大块空白。四个空间页现在使用视口最小高度，宽屏中图表占用剩余高度、摘要贴近底部操作栏，参数保持紧凑成组；窄窗口切回自然高度并可滚动。图表高度有 260..760px 展示边界，虚拟声场圆环和轴标签保持在自己的绘制范围内。

聚焦检查入口：`spatial-only`。实际 Avalonia 截图检查 1440×960、1280×800、1140×700、1920×1080、760×900，覆盖四个页面的宽 / 矮 / 窄 / 深色及交叉馈送 Classic / BS2B。断言宽屏监视区底部到视口底部间隙小于 3px，窄屏最后参数可滚动到；调整尺寸后的图表拖拽及原生参数回读通过。证据：`misc/dsp-spatial-size/`、`misc/dsp-spatial-size-ui.log`。本轮未改变 Core、音频协议或 DSP 参数语义。
