# Geometric ambience assets

Original ECHO artwork generated with OpenAI's image generation tool on
2026-09-05 for this project. No Folia source code or artwork is included.
The user approved the composition and its integration into ECHO.

- `ambient.png`: generated charcoal/slate background with geometry removed.
- `geometry.png`: generated transparent atlas of outline and filled circles,
  squares and triangles. The renderer supplies the original ECHO composition.

Source: the project's locally generated geometric ambience prototype. These
are project-generated assets, not a third-party stock or software dependency;
there is no third-party attribution or source-distribution requirement attached
to these files. They are included under the project's distribution terms.
Original PNGs are unmodified. Runtime downsamples them into bounded bitmaps;
light mode inverts the ambient and tints the atlas once when the theme changes.

There are no remote requests, user content, fonts or audio embedded in either
asset. The separate prototype reference image and its local test audio are not
included in the application.
